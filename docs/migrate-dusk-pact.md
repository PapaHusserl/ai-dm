# Правка сейва dusk_academy: Договор Хранителей

В пак добавлена сюжетная врезка «Договор Хранителей»: связь наследника ночного народа с человеком отравляет его и
остров, расставание возвращает равновесие, новое сближение запускает всё заново. Вход в историю — гадалка Тётушка
Мирта: в идущем мире `dusk_academy-d3de6c57` она придёт к героине через 1 игровой день от момента запуска скрипта,
со строкой «За кадром: …» на границе сцены. Скрипт задаёт этот срок (только он видит текущее время вашего сейва),
ставит стартовое состояние «Мира и Люциан вместе» и дописывает рассказчику знание о Договоре (описание мира, правда
мира, заметки Люциана и Мирты). Нужен Python 3 (других пакетов не нужно, репозиторий — только
для `git pull`). Подходят сейвы версий 9–12 (версию скрипт не меняет).

## Порядок

1. Закройте игру. **Скопируйте папку `saves/dusk_academy-d3de6c57` целиком** (например, как
   `dusk_academy-d3de6c57.bak`) — догрузка пака сама бэкап не делает.
2. Обновите репозиторий: `git pull`.
3. Запустите игру, загрузите мир. В начале увидите «Из пака добавлено: …» со списком: `faction:pact_keepers`,
   `npc:fortune_teller_haven` (если гадалки ещё не было), а также возможное другое из версий пака 2–3 — это нормально.
   Гадалка пока нигде не появляется. Выйдите из игры.
4. Выполните (путь — к папке мира внутри `saves`):
   - macOS / Linux: `python3 scripts/migrate_dusk_pact.py ~/путь/к/saves/dusk_academy-d3de6c57`
   - Windows: `py scripts\migrate_dusk_pact.py C:\путь\к\saves\dusk_academy-d3de6c57`
5. Скрипт напишет «Готово. Бэкап слота: …». Повторный запуск напишет «Уже применено» и ничего не изменит.
   Если пропустили шаг 3, скрипт откажется («Сначала запустите игру один раз…») и ничего не запишет; при другой
   версии сейва или другом мире — тоже.
6. Запустите игру и играйте. На первой границе сцены после того, как пройдёт игровой день, Тётушка Мирта окажется
   в локации героини. Пока Мира и Люциан вместе, раз в игровой день на границе сцены будет приходить одна беда на
   острове; после расставания — «Над островом прояснилось…». Рассказчик сам отмечает «вместе / расстались».
   Если беды продолжаются после явного расставания, сообщите Владу: значит, рассказчик не поставил флаг.

Правится только слот `auto`; другие слоты не меняются. Чтобы поправить другой слот, передайте путь к его папке
(`.../slots/auto-1`) — но сначала для него тоже нужен шаг 3.

## Откат

Бэкап лежит в `saves/dusk_academy-d3de6c57/backup-pact-<время>/auto`. Закройте игру, удалите
`saves/dusk_academy-d3de6c57/slots/auto` и скопируйте на его место папку `auto` из бэкапа. Либо откатите весь мир
скриптом `scripts/rollback_world.py`.
