# Партия «Обезоруживание» (disarm) — план

Папа-кабан, 2026-10-06, на утверждение. Идея пользователя 2026-10-06: отбирать оружие у врага в бою.
Код не меняется до аппрува. Встаёт ПОСЛЕ партии «Переговоры в бою» (docs/plan-combat-parley.md).

**Задача:** обезоруживание как механика движка: враг теряет «оружейные» атаки, оружие оказывается на земле
в зоне / в руках героя, его можно подобрать; трофей остаётся герою; враг может обезоружить героя.

## 0. Что уже есть (опора)
- `combat/actions/improvise.py::apply_disarm` — эффект импровизации (проверка навыка, СЛ из таблицы `dc` по категории
  от LLM): монстру вешает `ActiveEffect(id="disarmed", kind="flag")`, герою — `equipped.main_hand = None`.
- `combat/actions/attack.py::attacks_of`: у монстра с флагом `disarmed` → `[]` (теряет ВСЕ атаки, в т.ч. «Укус»,
  «Когти» — неверно для зверей); у героя оружие в инвентаре остаётся, `attacks_of` берёт любое оружие из инвентаря
  (`equip` в `perform`) — т.е. обезоруженный герой тут же бьёт тем же мечом. Оба поведения — дефекты, партия их чинит.
- Безоружный удар / импровизированное оружие у героя всегда есть (COMBAT-EXTRAS) — обезоруженный герой не беспомощен.
- Мастерство оружия: `combat/mastery.py::on_hit/on_miss` (sap/topple/push/slow/…) — в SRD 5.2 у оружия нет
  мастерства «disarm», ничего не добавляем.
- Контент: `content/models/monsters.py::MonsterAction` (name/kind/attack_bonus/damage_dice/…) — без связи с
  предметом; монстров 3 (`srd/data/monsters/guard|goblin_warrior|goblin_boss`), их атаки: Копьё, Скимитар,
  Короткий лук — все есть в `srd/data/weapons/*.yaml` (spear, scimitar, shortbow).
- `state/combat.py::Zone` (features — ZoneFeature, extra=forbid), `CombatState` (extra=forbid),
  `TurnState` (action/bonus/reaction/move/…; свободного взаимодействия с предметом нет).
- `rules/inventory.py::add_item/remove_item/equip/unequip`; лут — `rules/loot.py` (только деньги по CR,
  `loot_individual`), предметы с врагов сейчас не выдаются.
- `available.py::escape_options` — образец «опции по эффекту на участнике»; `standard.py` — образец perform.
- Сейв: `persistence/migrations/__init__.py`, `CURRENT_SCHEMA_VERSION = 5`.

## 1. Опора на SRD 5.2 и выбор механики
- SRD 5.2 (2024): базового действия Disarm нет. Есть мастерство оружия (без disarm), манёвр Battle Master
  «Disarming Attack» (вне SRD-подкласса — не берём), DMG 2014 «Disarm» (вариант: атака оружием против
  проверки Атлетики/Акробатики цели; цель держит двумя руками — преимущество у цели; размер больше атакующего —
  преимущество у цели, меньше — помеха; успех → предмет падает к ногам цели).
- **Рек. (В1): отдельное действие движка `disarm` в меню, по DMG-варианту**, вместо слабо управляемого improvise:
  - стоимость: одна атака из действия Атака (как Захват/Толчок в SRD 5.2 — тратит `attacks_left`/action через
    существующий путь атаки), только ближний бой (цель в той же зоне), цель — `active`, у цели есть оружие (п.2);
  - бросок: проверка героя Атлетика (Сила) — или Акробатика? По DMG атакующий делает **бросок атаки** оружием.
    Рек.: бросок атаки текущим ближним оружием (бонус как у атаки, без урона) против проверки цели
    Атлетика/Акробатика (лучшее из модов Сил/Лов + владение если есть; у монстра — мод. характеристики, навыков
    в модели нет). Альтернатива В2: спасбросок Сил/Лов цели против СЛ 8+Сил/Лов+БМ героя (как Толчок SRD 5.2) —
    проще, единообразно с `area`-спасбросками монстров.
  - модификаторы (у цели): хват двумя руками (`two_handed` в свойствах оружия, у героя также versatile без
    щита/off_hand) → преимущество; размер цели больше героя → преимущество за каждую ступень? (DMG: просто
    преимущество), меньше → помеха. Состояния (prone/restrained/…) — через существующие модификаторы проверок.
  - конфиг `[disarm]` в `config/defaults.toml`: `enabled`, `mode = "attack_vs_check"|"save"`, `outcome`.
- improvise «disarm» оставить, но **перенаправить** `apply_disarm` на общую функцию `combat/disarm.py::disarm_target`
  (одна логика исходов); категорию СЛ по-прежнему задаёт LLM (это импровизация). В промпт рассказчика — строка
  «отбор оружия — действие disarm в меню; improvise disarm только для нестандартных способов (кнут, заклинание)».

## 2. Какое действие монстра «оружейное»
Атаки монстра — действия, не предметы. Рек. (В3): **явная разметка в контенте**:
- `MonsterAction.weapon_id: str | None = None` — id из `srd/data/weapons` (контент-модель, НЕ сейв; extra в
  ContentModel проверить). Валидатор загрузчика: weapon_id существует в registry.
- Разметить 3 монстров: guard «Копьё»→spear; goblin_* «Скимитар»→scimitar, «Короткий лук»→shortbow.
- Действие без `weapon_id` (Укус, Когти, Хлыст щупальцем) — естественное, обезоружить нельзя; монстр без
  оружейных действий не является целью disarm (опции нет).
- Фолбэк-эвристику по имени («меч», «лук») НЕ делаем — недетерминированно, мутанты.
- `attacks_of` (ветка монстра): если на существе флаг `disarmed` с `params.weapon_id=X` → пропускать действия с
  этим weapon_id (а не все). Если оружейных не осталось — добавить монстру «безоружный удар»
  (`AttackInfo("unarmed", melee, bonus = мод.Сил + БМ по CR, урон 1+мод.Сил дробящий)`), только для
  `creature_type in [disarm].unarmed_types` (humanoid, giant… рек. — гуманоиды). БМ по CR — проверить, есть ли
  функция (rules/derived или cr-таблица); иначе +2.
- Multiattack (`combat/actions/multiattack.py`): шаги с отключённым действием пропускаются; если пусто —
  мультиатаки нет (`multiattack_options` скрывает). Проверить check_multiattack-валидатор — он контентный, не мешает.
- Два одинаковых оружия (стражник «Копьё» — можно метнуть): отбираем одно — действие пропадает целиком
  (упрощение, запас копий не моделируем).

## 3. Исходы и предмет на земле
Рек. (В4): **оружие падает в зоне цели** (DMG); бонус — если у героя свободна рука (нет off_hand и щита? проще:
нет оружия в main_hand ИЛИ герой атаковал безоружным) — сразу в руки героя («выхватил»). «Отброшено в соседнюю
зону» — НЕ делаем (нужна выборка зоны, мало ценности); оставить как возможный исход improvise push+disarm — нет.
- Новое состояние боя: `CombatState.ground_items: list[GroundItem]`, `GroundItem{item_id, zone_id, owner_ref|None,
  qty=1}` (owner_ref — у кого выбили, для возврата «своего» монстру и лога). `extra=forbid`, но поле с default —
  старые сейвы читаются (как `moves`, `savage_used`); миграция не нужна (см. «Миграции»).
- Обезоруживание героя: `main_hand=None` + `remove_item(hero, weapon_id)` + GroundItem (сейчас предмет остаётся в
  инвентаре — дефект). Если у героя несколько единиц — убирается 1.
- Обезоруживание монстра: флаг `disarmed` с `params={"weapon_id": X}` (kind "flag" → "disarmed"; несколько
  флагов — несколько отобранных) + GroundItem(owner_ref=монстр).
- Именованный NPC (creature в world.npcs): то же, флаг на его CreatureState; после боя флаг снимается (см. п.5).

## 4. Подбор оружия с земли
- SRD 5.2: поднять предмет — взаимодействие с объектом (одно бесплатное за ход), второе — действие Utilize.
- Рек. (В5): ввести `TurnState.free_interaction: bool = True` (default — старые сейвы ок); опция
  `pickup:<idx>` kind "pickup" в новом `available.py::pickup_options` (образец `escape_options`): предмет в зоне
  участника; стоимость — свободное взаимодействие, если не потрачено, иначе действие. Сброс в `start_turn` вместе
  с прочими полями TurnState.
- perform в `combat/actions/standard.py::pickup` (или `item.py` — рядом с предметами; рек. item.py):
  - герой: `add_item` + `equip(main_hand)` если рука свободна (иначе только в инвентарь); GroundItem удалить.
  - монстр: поднимает только **своё** (owner_ref == ref) или любое оружие, соответствующее его оружейному действию
    (weapon_id совпал) → снять флаг `disarmed` с этим weapon_id. Чужое оружие монстр не использует (у него нет
    AttackInfo под предмет) — упрощение.
- ИИ `combat/controllers.py::EngineTactics`: обезоруженный монстр в зоне со своим оружием → pickup (дешёво,
  если свободное взаимодействие) перед атакой; в другой зоне → move+pickup, если нет врага рядом; иначе
  безоружный/естественная атака. `AutoHeroController`: подбирать своё оружие, если в руке пусто.
- Карта/TUI: строка «На земле: скимитар (зона B)» — `ui` рядом с выводом зон/движения (найти рендер `moves`).

## 5. После боя (трофей и лут)
- В `end.py::conclude`: рек. (В6) — предметы на земле в зоне боя, если бой выигран героями
  (`outcome` победа/враги бежали/сдались), **автоматически** в инвентарь первого героя-не-dead (или того, кто
  выбил: owner GroundItem → `taken_by`); свои предметы героев возвращаются владельцам. Поражение/бегство героев —
  предметы героев теряются (лог «меч остался на поле боя»), запись в `world` не делаем (В7: сохранять ли как
  предмет локации — нет механизма, рек. не делать).
- Оружие, выхваченное в руки во время боя, уже в инвентаре — остаётся.
- Связь с лутом: `rules/loot.py` выдаёт только монеты по CR — не трогаем. Рек. (В8): оружие поверженных
  обезоруженных и НЕ обезоруженных врагов в лут не добавлять в этой партии (иначе каждый бой даёт 3 скимитара);
  трофей — только реально выбитое. Отдельная задача в BACKLOG: «предметы с тел врагов».
- Снять флаги `disarmed` и `ground_items` в conclude (бой закончен; уцелевшие NPC — с флагом? рек.: флаг снять,
  NPC считается «подобравшим» своё, если оружие не у героя; если у героя — у NPC в world нет инвентаря, ничего).

## 6. Может ли враг обезоружить героя
- Рек. (В9): да, симметрично, но редко: `EngineTactics` использует disarm только если у монстра есть флаг
  контента `Monster.tags` содержит `disarmer` (никто из текущих — нет) ИЛИ конфиг `[disarm].enemy_chance`
  (по умолчанию 0). Без этого ИИ-монстры начнут обезоруживать каждого героя — плохой игровой опыт.
- Атака монстра для броска disarm: его лучшее оружейное ближнее действие (attack_bonus). Обезоруженный герой:
  безоружный/импровизированное/другое оружие из инвентаря (остаётся доступным — это верно), pickup своего.

## 7. Пересечения с партией «Переговоры» (parley)
Parley трогает: новый `combat/actions/parley.py`, `Participant.status += "surrendered"`, `end.py::set_outcome`,
`controllers.py`, `protocol/requests.py` (PlayerAction.parley), промпт рассказчика.
- Disarm встаёт поверх: в `conclude` трофеи раздавать и при `surrendered` врагах (сдавшийся отдаёт оружие →
  рек. В10: сдавшийся враг автоматически роняет оружейные действия на землю; т.е. capitulation = disarm всех
  оружий). Делать после слияния parley, используя его статус.
- Parley-модификатор СЛ: «цель обезоружена → −2» (предложение для конфига `[parley]`, добавить в этой партии,
  если parley уже слит).
- Конфликт по файлам: `controllers.py` (обе партии добавляют ветки EngineTactics) — разные ветки; `available.py`
  `list_options` — добавить `pickup_options`/`disarm_options` в конец списка; промпт — отдельные строки.
- `ActiveEffect` флаги: parley кладёт `parley_tried`, disarm — `disarmed` с params; не пересекаются.

## Миграции сейва

## Тесты (TDD, писать первыми)
Контент:
- MonsterAction.weapon_id валиден; неизвестный id → ошибка загрузки; 3 монстра размечены.
Опции:
- герой рядом с гоблином со скимитаром → опция disarm:goblin:scimitar; в другой зоне — нет; цель без оружейных
  действий (зверь) — нет; у героя нет действия/атак — нет.
- после первой атаки Дополнительной атаки disarm доступен второй атакой (тратит attacks_left).
Состязание:
- успех → флаг disarmed{weapon_id}, GroundItem в зоне цели, лог; провал → ничего, атака потрачена.
- оружие two_handed у цели → преимущество цели; цель крупнее → преимущество; мельче → помеха; оба → взаимно гасятся.
- режим save (В2) — СЛ 8+мод+БМ, спас цели.
- grab: свободная рука героя → оружие сразу в инвентарь+main_hand, GroundItem нет.
Монстр без оружия:
- attacks_of гоблина без скимитара → только лук; без обоих → безоружный удар (гуманоид); зверь — отбирать нечего.
- старый флаг без params → все оружейные отключены, естественные остаются.
- мультиатака с отключённым шагом — шаг пропущен.
Герой обезоружен:
- main_hand None, предмет удалён из инвентаря (1 шт.), GroundItem owner=герой; attacks_of без этого оружия;
  безоружный/импровизированное есть.
Подбор:
- первое подбирание — свободное (action остаётся); второе — тратит действие; без действия — опции нет.
- монстр подбирает своё → флаг снят, атака вернулась; чужое оружие монстр не подбирает.
- ИИ обезоруженного монстра в зоне с его оружием выбирает pickup.
После боя:
- победа: ground_items → инвентарь героев (своё — владельцу), флаги сняты, ground_items пусты.
- поражение: предметы героев на земле теряются, лог.
- выхваченный в бою трофей в инвентаре после конца боя.
- loot_individual (деньги) не изменился (регрессия).
Регрессии:
- improvise disarm идёт через disarm_target; improvise прочие эффекты как раньше.
- враги по умолчанию (enemy_chance=0, без тега) не обезоруживают.
- загрузка сейва v5 (бой без новых полей) — ок.
- с parley: сдавшийся враг → оружие на земле (если В10 принят и parley слит).
Мутационное тестирование — по правилам HANDOFF (без недостижимых фолбэков).

## Риски
- R1 Разметка weapon_id для будущих монстров — забудут → монстр неотбираемый. Валидатор-предупреждение для
  humanoid без weapon_id в тесте контента.
- R2 Раздувание меню: disarm × цели × оружия цели. Рек.: одна опция на цель (лучшее/первое оружие), выбор оружия
  только если у цели два оружейных действия.
- R3 Exploit: обезоружить → подобрать → у героя 10 скимитаров. Ограничено реальным числом выбитого; лут не трогаем.
- R4 Ломается баланс: обезоруженный гоблин-лучник без лука = безоружный 1+Сил. Это и цель механики; следить в
  живом прогоне.
- R5 Сейв посреди боя со старым флагом `disarmed` — покрыто трактовкой «все оружейные».
- R6 Пересечение с parley в `controllers.py`/`end.py` — партия строго после слияния parley, ребейз планом.
- R7 Акробатика vs Атлетика у монстров: навыков в модели нет → используем лучший мод. Сил/Лов (+БМ по CR не
  даём — владение неизвестно). Упрощение.
- R8 Монстр с метательным копьём (guard) — «копьё» отобрано целиком, бросок тоже пропадает (одно действие).

## Правки по ревью: Отбор оружия: отличия реализации от плана (kaban, 2026-10-06) (бывш. docs/decisions/combat-disarm-review.md)

План: docs/plan-combat-disarm.md; ответы проектировщика -- В1–В11 по рекомендациям.

### Отличия и уточнения
1. В2: только вариант «бросок атаки против проверки цели»; режим `[disarm].mode = "save"` не делался (в конфиге нет).
   Порядок: цель бросает проверку (Атлетика/Акробатика героя, лучший мод. Сил/Лов монстра), её итог -- КД для броска
   атаки героя (строка «проверка цели»).
2. Опция по строке на оружие цели (`disarm:<цель>:<оружие>`, params `target`, `weapon_id`), а не одна на цель (R2).
3. Бросок -- первая ближняя атака героя (оружие в руке, затем из инвентаря, затем безоружный; подручное не берётся).
   «Выхватить в руки» (grab) -- когда этой атакой оказался безоружный удар и рука свободна (двуручное при щите не берётся
   в руку, остаётся в инвентаре).
4. В9: монстр обезоруживает только с тегом `disarmer` (опция есть только у него, `EngineTactics` её берёт); `enemy_chance`
   не делался (тактика без бросков).
5. ИИ: `pickup` монстра -- первым делом, только в своей зоне (шаг к оружию в соседней зоне не делался); авто-герой
   подбирает, если рука пуста.
6. Безоружный удар монстра: если после отбора нет ни одной атаки (естественные атаки остаются, кулак не добавляется) и
   тип в `[disarm].unarmed_types` (по умолчанию `humanoid`, `fey` -- гоблины в SRD fey); бонус = мод. Сил +
   `[disarm].unarmed_proficiency` (2, функции БМ по CR в коде нет), урон 1 + Сил, не ниже 0.
7. Монстр подбирает оружие, чьё действие у него отобрано (свое или такое же чужое); флаг снимается.
8. В10: `parley.apply_surrender` вызывает `disarm.surrender_drop` (оружие на землю). −2 к СЛ переговоров обезоруженному --
   `[parley].disarmed_bonus` (в `parley_dc`).
9. Конец боя (`end.settle_ground`): победа/ended_by_master при живом герое -- выбитое в инвентарь (своё -- владельцу,
   иначе первому живому герою); иначе предметы героев теряются (лог), чужие исчезают; метки `disarmed` снимаются.
10. Карта боя: строка «На земле: …» (`battle_map.ground_line`, `battle_map_lines(..., registry=None)`).
11. Рассказчик: строка в narrator_rules.md (disarm и pickup -- из `combat.options`; improvise disarm -- нестандартные способы).
12. Схема сейва: новые поля `CombatState.ground_items`, `TurnState.free_interaction`, `GroundItem` -- с умолчаниями, версия 5.

### Мутации (kaban-doeba, 2026-10-06)
`make mutate MOD="ai_dm.combat.disarm ai_dm.combat.end"` с TESTS на тесты партии: после разбора 8 выживших в новом коде,
все эквивалентные. `settle_ground` — 0 выживших. Модули `available`, `attack`, `controllers`, `battle_map` в этот прогон не
входили (лимит времени; изменённые функции покрыты поведенческими тестами, `make cov` 95,92%).

| Мутант | Что изменено | Почему эквивалентен |
|---|---|---|
| disarm.strike_info 5 | `and` -> `or` в выборе ближней атаки | безоружный удар всегда стоит в `attacks_of` перед «improvised», первая ближняя атака та же |
| disarm.strike_info 10, 11 | строка `"improvised"` испорчена | то же |
| disarm.target_check 1 | `skill = None` -> `""` | у монстра `skill` в запросе не влияет на бросок |
| disarm.target_check 54 | убран `actor_id` | в `roll` для проверки не используется |
| disarm.target_check 57 | убран `bonus=` | бонус считается из `bonus_parts`, `bonus` дублирует |
| disarm.target_check 69, 73 | `modifiers=None` / не передан | реестр модификаторов по умолчанию даёт тот же результат (отравленный всё равно бросает с помехой) |

Остальные выжившие в `end.py` (`set_outcome`, `conclude` — концентрация, скрытность, подпись исхода) — старый код, не новые
строки партии; в BACKLOG.

### Ревью mama-kaban (2026-10-06)
По важности:
1. **Ничья в состязании** (`disarm.perform`): `roll_attack(..., check.total)` трактует итог проверки как КД, при равенстве
   засчитывается попадание. По правилам состязаний ничья оставляет положение как было -- цель удерживает оружие.
   Предложение: передавать `check.total + 1` (подпись «проверка цели» с итогом проверки) или сравнивать итог атаки с
   `check.total` строго; тест на ничью (фиксированный rng).
2. **ИИ зацикливается на disarm** (`EngineTactics.pick_special`): монстр с `disarmer` ставит disarm выше multiattack и
   атак, пока у цели есть оружие. Герой подбирает выбитое свободным взаимодействием -- босс каждый ход только
   обезоруживает и не наносит урона. Предложение: disarm только если цель ещё не обезоруживалась этим монстром
   (флаг/метка на бой) или только когда multiattack недоступна; тест «два хода подряд -- второй ход атака».
3. **Трофеи при победе** (`end.settle_ground`): чужое оружие (owner -- монстр) уходит первому живому герою. Проверить,
   не дублирует ли это обычную добычу с монстра (лут после боя) -- иначе меч гоблина выдаётся дважды. Поражение:
   своё оружие героя теряется насовсем (уже удалено `strip_weapon`) -- по плану, но в лог/рассказчику стоит явно.
4. **KeyError в переговорах** (`parley.menu_entries` перебирает всех участников, `engine.monster` у героя на стороне
   врагов): старый баг, `disarm` его не трогает, но `parley_dc` теперь зовёт ещё `has_flag`. В BACKLOG с тестом.
5. **Оружие из рюкзака** (`strike_info`): по SRD 5.2 достать одно оружие -- часть атаки, так что бить копьём из рюкзака
   допустимо. Но следствие: «выхватить в руки» (grab) срабатывает только у героя без единого оружия. Оставить, описать
   в отличии №3 явно (уже почти описано).
6. **Монстр с флагом и только естественными атаками** -- корректно: weapon_id у когтей None, `result` не пуст, кулак не
   добавляется. Старый флаг без weapon_id (`all_lost`) -- тоже без кулака, если есть естественные. Ок.
7. **Схема v5**: новые поля с умолчаниями, старые сейвы грузятся; `lost_weapons` понимает старый флаг без weapon_id. Ок.
8. **Тесты не хватает** (мутации не гонялись): `available.disarm_options` -- цель в другой зоне/неспособная, нет
   `may_disarm`; суффикс «(ещё N из 2)» для disarm; `pickup_options` -- cost free/action и пусто без обоих;
   `controllers.pick_special` -- герой не берёт pickup/disarm, порядок escape > pickup > disarm;
   `AutoHeroController` pickup только при пустой руке; `attack.monster_unarmed` -- тип не из `unarmed_types`, урон
   не ниже 0; `multiattack` пропуск отключённого шага; `battle_map.ground_line` при `registry=None`. Прогнать
   `make mutate MOD="ai_dm.combat.available ai_dm.combat.controllers"` хотя бы по новым функциям.

Мелочь: в `disarm.perform` условие `engine.heroes[ref]` держится только на том, что у монстров `weapon_id` в AttackInfo
всегда None -- добавить `engine.is_hero(ref) and` для ясности.

**Вердикт:** нужны правки (п. 1, 2; п. 3 проверить).
