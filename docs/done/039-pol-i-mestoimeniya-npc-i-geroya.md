(проектировщик, 2026-10-12; сделано в К0-фикс-б)
Пола нет нигде (ни NPC, ни героя, ни паков) — рассказчик угадывает по имени: «матушка Рут усмехается в седые усы»;
без пола не работает романтика. Решения проектировщика: в К0-фикс; поле пола (мужской/женский/другой) + необязательные
местоимения — у NPC (пак и создание мастером) и в листе героя; старые миры — пустое = не задан, без миграции, сейв v9,
мастер проставляет при следующем появлении NPC.
Сделано (К0-фикс-б): state/gender.py, поля gender/pronouns у NPC, героя, запросов и пака, шаги визарда «Пол» и «Местоимения»
(«-» = по полу), в промпт ключи только если заданы, правила рассказчика; пол в /sheet не показываем (Q12 в); пол проставлен
именованным NPC паков там, где он ясен из текста (остальным ставит рассказчик через npc_update).
