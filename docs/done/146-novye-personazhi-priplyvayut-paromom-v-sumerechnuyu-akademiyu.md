# 146. Новые персонажи приплывают паромом в Сумеречную Академию
status: done
priority: medium
updated: 2026-10-22

Запрос проектировщика: в идущее повествование Сумеречной Академии (сейв dusk_academy-d3de6c57) ввести новых
персонажей так, будто они приплыли новым паромом с материка, а не «всегда были». Решения проектировщика (2026-10-22):
персонажей пишет сам (имена, роли, мотивы — npcs.yaml пака); паром через 1–2 игровых дня от текущего момента сейва;
заранее слух «завтра паром с материка», затем прибытие; после схода расходятся по своим местам; только текущий мир
(абсолютный `time_after`); паром разовый. Груминг свинопаса: `merge_new` ставит NPC пака сразу на локацию — прибытие
собирать связкой «NPC без локации + триггер `time_after` + `then` роли world: перестановка и `world_notice`»;
проверить, что такой NPC не виден рассказчику до прибытия. Перед загрузкой с новым паком — бэкап сейва. Рядом: 20, 83.
