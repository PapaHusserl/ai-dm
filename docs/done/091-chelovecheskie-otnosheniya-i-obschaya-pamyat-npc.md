# 91. Человеческие отношения и общая память NPC
status: done
priority: high
updated: 2026-10-20

(проектировщик, 2026-10-19) Тему нужно расширить: не только интимные отношения, а человеческие вообще — дружба, шутки,
общие миссии. NPC должны помнить, как и мир, события, которые связывают их с персонажем и с другими NPC.

Находка по живому миру drunk_dragon-00000001 (автосейв 19.10, только чтение): у Лиры (спутница, близкие отношения с
Греем) отношение 95, но память о герое (`npc.memory`) пуста — 0 сцен; заметки (`notes`) — только роль и место в отряде;
в журнале героя (`/lore`) одна запись «Знакомство: Лира»; целей нет. Связь держится только в выжимках сцен и главы 7
(«провели страстную ночь…»); общая выжимка игры называет Лиру «спутницей». Когда выжимки уходят из контекста, остаются
число 95 и слово «спутница»; шутки, привычки, общие события нигде отдельно не хранятся. `npc.memory` пишут бой и запрос
рассказчика, но правила его к этому почти не подталкивают; связей «NPC — NPC» с общей историей нет (есть только
`family` — задел).
