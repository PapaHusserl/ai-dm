# 69. Опыт `award_xp` выдаётся почти каждый ход
status: done
priority: high
updated: 2026-10-18

(ЖП игрока dusk_academy, 2026-10-17, без приоритета)
Наблюдение игрока на другой машине: героиня получает по 900 опыта на каждом шаге (900 = 5-й ур. × `minor` 10 %
или 2-й ур. × `major` 50 %). Гипотеза по коду, без журнала: рассказчик зовёт `award_xp` повторно — правила не
говорят, когда давать опыт (`narrator_rules.md:113` — только «через инструмент»), защиты от повтора нет (как
`gold_repeat`/`rest_repeat` в ТМ; `turn_data` с прошлыми наградами может провоцировать копирование, T6/Ф3).
Подтвердить — `/report` или журнал с машины игрока (строки «Опыт: +900 (…)»).
Мини-фикс по образцу ТМ: защита `xp_repeat` (не чаще одной квестовой награды за сцену или кулдаун; rejected +
авто-репорт) и правило в промпте — за что опыт (завершённая цель, крупное открытие, не каждый шаг).
