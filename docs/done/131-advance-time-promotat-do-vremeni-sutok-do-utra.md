# 131. advance_time: промотать до времени суток («до утра»)
status: done
priority: low
updated: 2026-10-22

(ЖП4, репорт t623 `rest_repeat`+`missing-mechanic`, ход 622) Игрок: «засыпаем до самого утра». В 20:06 `rest long`
отклонён (`rest_repeat`, «снова возможен с 21:50» — текст 100 сработал). Рассказчик: «`advance_time` не позволяет
указать точный срок» → `unsupported_action`, затем 2× `advance_time hour` (22:06) и повторный `rest long` — принят,
подъём 06:06. Итог верный, но случайно: категорий только minute/hour/day/week/month. Нужен сдвиг до времени суток
(до утра / до часа N) или до момента, когда снова можно длинный отдых. По решению проектировщика 2026-10-21 —
в резерв Фикс ЖП4 (место — архитектор).
