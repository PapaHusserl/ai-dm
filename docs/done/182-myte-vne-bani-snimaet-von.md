# 182. Мытьё вне бани снимает вонь
status: done
priority: medium
updated: 2026-10-25

Вонь (`smelly`) снимает только платная услуга с бонусом «чист» (баня, комната с лоханью — `rules/boons.py`,
`mark_washed`). Мытьё в рассказе (река, озеро, бочка, ведро) движок не видит: флаг `washed:<hero>` не сбрасывается,
через `hygiene_days` ночной тик (`world_sim/hygiene.py`) снова ставит вонь. Живой мир drunk_dragon, 2026-10-25: герой
искупался, вонь всё равно пришла (Влад). Нужен путь для рассказчика отметить мытьё (инструмент или поле ответа),
возможно с условием воды в локации; баня остаётся удобным путём. До реализации вонь снята у героя правкой сейва.
