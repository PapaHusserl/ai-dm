# 21. База знаний игрока: «что я знаю о…»
status: done
priority: medium
updated: 2026-10-18

(идея проектировщика, 2026-10-06)
Мета-игровой вопрос игрока — что герой знает о персонаже, локации, народе/фракции, боге, текущей ситуации.
Ответ — строго из знаний героя (не из полного состояния мира), без спойлеров секретов.
Опора: NPC.known_to_player (TZ 4.1, раскрытые секреты), выжимки сцен/глав (память этапа 4), хроника world_sim,
благосклонность богов (approx_label), бестиарий (BACKLOG п. 3 — «что игрок узнал о существе»).
Набросок (при проектировании — отдельный план):
- Журнал знаний героя: записи по сущностям (npc/location/faction/god/creature/situation) с источником и временем
  («видел», «слышал слух», «рассказал X»); пополняет движок/рассказчик запросом протокола, а не свободным текстом.
- Команда вне хода (не тратит время мира): `/знаю <что-то>` или `/lore` + список сущностей; в TUI — окно-справочник.
  Свободная фраза «что я знаю о …» классифицируется как мета-вопрос (не действие героя).
- Ответ: шаблон из журнала (дёшево) + опционально пересказ дешёвой моделью; LLM видит только журнал героя.
- Забывание/искажение (TZ: «второстепенные NPC исчезают из знаний героя — *забыто*») и «известное имя» NPC
  (BACKLOG 20, `known_name`) — общая модель знаний.
- Связано с: BACKLOG 20 (живые NPC), 3 (бестиарий), 8 (книга по истории).
