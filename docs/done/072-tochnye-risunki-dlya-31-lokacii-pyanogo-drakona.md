# 72. Точные рисунки для 31 локации «Пьяного дракона»
status: done
priority: medium
updated: 2026-10-19

(бывш. 5а; решение проектировщика В-5, 2026-10-06)
Сейчас «Пьяный дракон» берёт рисунки по тегам локации (таверна, город, деревня, болото, руины, храм/святилище, магазин,
горы/предгорья, гробница, равнина). Без рисунка остаются локации без подходящего тега: dead_pine_gorge, deep_shaft,
olbrecht_manor, varen_manor, watch_tower_outpost, white_winds_ledge, wolf_teeth_pass (тегов нет), а также ash_forge, black_spring,
city_ratusha, city_waterworks, east_shaft, grey_quarter, viper_island. Нужно: нарисовать точные рисунки (≤ 36×14, ASCII + ░▒▓) для
всех 31 локаций и прописать их в `art/data/index.yaml` (раздел `locations`). Рисунки Вейла и все остальные — на просмотре
пользователя (качество рисунков агента субъективно, любой файл можно заменить).
R8 (2026-10-18, решение 5а): плавающая-наполнитель — без номера в очереди, делается в любое окно ожидания (журнал игрока,
живой прогон) облегчённым конвейером «д» (загрузка `art/data/index.yaml`, просмотр пользователя); зависимостей нет.
