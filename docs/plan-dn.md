# Шаг ДН — Минимум день и ночь

BACKLOG 36, 161; при касании 148, 176, 113 (только `rest_redundant`). 153 и 160 — вне шага (груминг: 153 без полей
сейва не ложится, остаётся idea; `tick_days` шаг не трогает).

## Суть

Мастер и игрок знают время суток. Ночью мастер обыгрывает сон NPC и закрытые лавки по правилу рассказчика, движок
не запрещает. Сдвиг времени на N дней. Сводка сцен считает дни по данным движка.

## Решения

Проектировщик, 2026-10-25, груминг (окна по вопросам свинопаса):

1. Ночной визит: мастер видит часть суток, по правилу рассказчика ночью NPC спят, лавки закрыты, кроме трактира и
   стражи; исход визита (разбудил, отказ, наценка) — по суждению мастера. Движок не запрещает, полей сейва нет.
2. Игрок видит часть суток словом в статус-строке рядом с часами: «утро / день / вечер / ночь».
3. Границы: утро с 6:00, день с 12:00, вечер с 18:00, ночь с 21:00 (вариант предложил оркестратор, а не
   свинопас; рекомендация свинопаса была 6/10/18/22).
4. 161: «ждём 8 дней» — ровно 8 дней, строка ленты «Прошло 8 дней»; потолок — не больше года за раз, сверх — отказ.
5. 161: починка счёта дней в сводке — в ДН; summarizer получает от движка даты начала и конца сцены и число дней.
   Если дата начала сцены требует нового поля сейва — пункт уходит из ДН.

Проектировщик, 2026-10-25, развилки плана (по одному окну, все — по рекомендациям папы):
