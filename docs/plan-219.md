# Шаг 219 — второе часовое дело подряд теряет час (BACKLOG 219, хвост 220)

## Суть

Защита `time_repeat` считает ход с `hour` без других инструментов «праздным» и отклоняет следующий `hour`
в окне 2 хода; час работы без инструментов (t1364 чистка снаряжения, t1367 баня, drunk_dragon) теряется —
ход принят, часы +15 вместо +1 ч. Груминг — свинопас, аудит груминга — свекровь (2026-10-30, scratchpad сессии).

## Решения

Проектировщик, 2026-10-30, окнами по развилкам свинопаса:

1. Р1 = Б: отказ `time_repeat` только на третий праздный час подряд (в окне уже два праздных часа); два часа
   подряд проходят всегда. Риск ТХ «ложный отказ на двух часах ожидания» пересмотрен: ложный отказ остаётся
   только на трёх часах ожидания подряд.
2. Р2 = А: сдвиги, кратные часу (day/week/month, ровный `until`), считаются праздным часом, как в ДН.
3. Р4 = А: окно `time_repeat_turns` остаётся 2.
4. Р5 = А: при отказе как сейчас — ход принят, часы +15 (ДН 25).
5. Р6: narrator_rules.md:134 — «третий `hour` подряд без пути и дела движок отклонит».
6. Р7 = А: перед закрытием короткий живой прогон — два часовых дела подряд, часы +1 ч и +1 ч.

7. Р8 = (3), 2026-10-30, по рекомендации папы: порог = окно — отказ, когда все `time_repeat_turns` последних
   ходов — праздные часы; нового ключа нет.
8. 2026-10-30, Влад: «потом потестирую, закрываем шаг» — шаг закрывается без живого прогона Р7; прогон Влад
   проведёт позже, вне шага.

### Правила, которые меняются (первым пунктом аппрува)

1. `time_repeated` (`protocol/handlers/resources.py:967-978`). Было: цикл по `recent_turns[-window:]`, первый ход с
   `any(n and n % seconds == 0 for n in shifts) and set(turn.requests) <= idle` → его `turn_seq`, иначе `None` —
   один праздный час в окне блокирует следующий `hour`. Станет: праздный час считается так же (кратный сдвиг,
   `requests ⊆ {advance_time, offer_choices}` — Р2 = А), но отказ — только когда в окне таких ходов не меньше
   порога «два»: при Р8 = (3) — `turns = recent_turns[-window:]; len(turns) == window and all(idle_hour(t) for t in
   turns)` → список `turn_seq` этих ходов, иначе `[]`; при Р8 = (1)/(2) — `sum(idle_hour(t) for t in turns) >=
   порог` → список `turn_seq` праздных часов. Ход с отказом `time_repeat` праздным часом не считается: в `outcomes`
   у него «advance_time: отклонено (повтор часа)» (`game/turn.py:451`), строки «Время идёт» нет, `time_log_seconds`
   → `None`; то же для хода только с авто-тиком (ДН, правка по ревью 2 — строки нет).
2. `time_by_category` (`resources.py:988-995`), ветка `hour`: было `if seq is not None: rejected("повтор часа",
   f"Час уже прошёл на ходу {seq} без пути и дела. …")` → станет `if seqs: rejected("повтор часа", f"Два часа
   подряд уже прошли на ходах {', '.join(map(str, seqs))} без пути и дела. Время не двигай: опиши сцену по факту, а
   ожидание продолжай только по просьбе героя.", report_tag="time_repeat")`. Порядок проверок 217 (сон раньше

**Поведение:** меняется — (а) `hour` после одного праздного часа (`hour`, `hour × N`, `day`/`week`/`month`, ровный
`until` — Р2 = А) принимается, часы +1 ч (чинит t1364 и t1367); (б) отказ `time_repeat` — после двух праздных
часов подряд; ход с отказом окно обнуляет, поэтому ритм праздных часов без дела: принят, принят, отклонён, принят,
принят, отклонён (следствие Р1 = Б + Р4 = А + Р5 = А; раньше — принят, отклонён, отклонён, принят, тест

Не меняется: `travel_to`, `until` (кроме записи в окно), сон 217, два `hour` в одном ходу (известное ограничение ТХ),
`time_repeat_turns = 0` — выкл.

### Развилки и риски
