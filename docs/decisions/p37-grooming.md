## Груминг

### Готовность

**Не готова к плану до ответов на В1–В3** (блокирующие). В4–В8 можно закрыть по рекомендации.
Схема сейва не трогается, v9. Строка роадмапа опирается на два допущения, которых в коде нет: «реестр паков» и

### Что есть в коде (факты)

- `CampaignManifest.preset: str = ""` (`campaign/models.py:77`) — **ни в одном паке не заполнено** (grep по
  `campaigns/*/campaign.yaml` пуст). Обратный индекс «пресет → паки» из манифестов сейчас пуст.
- `manifest.preset` — не метка, а **тон по умолчанию**: `pick_tone` (`build.py:127–133`) берёт `preset_id or
  manifest.preset`. Пункт меню «Как в паке» возвращает `None` (`cli.py:194–201`) → сработает `manifest.preset`.
  Значит прописать `preset: romantic` в `dusk_academy` = сменить её тон по умолчанию: оси и голос пресета вместо
  тона пака (`apply_preset`, `presets.py`), `romance` станет `чувственно` вместо `намёки`. Побочный эффект.
- **Реестра паков нет.** Пак выбирается только флагом `--campaign`, по умолчанию `vale` (`cli.py:69, 809`).
  Перечисления `campaigns/` в коде нет. `campaign_registry` (`cli.py:589`) — реестр *контента* одного пака, не список паков.
- **Пикера пака нет.** Порядок старта нового мира (`cli.py:840–861`): пак уже загружен → выбор героя (`choose_hero`,
  только выбор пункта) → `choose_preset` → создание героя на лету/пошагово (вызовы модели, деньги; cli.py:857–870).
  К моменту выбора пресета пак зафиксирован, но деньги ещё не потрачены (поправка аудита). «Выбрать подходящий пак» в
  этой точке = перезапуск.
- Пикер пресета: `choose_number` → TUI (`pick_tui`) или `ask_choice` в `--simple`; один код на оба режима.
  Пункты: «Как в паке» + `preset_label` (имя, «в духе «codename»», описание).
- `--preset` (`cli.py:102`, проверка `preset_refusal` 696–707): при нём меню пресета не показывается; в заметках старта
  строка «Мир: …, пресет X» (`cli.py:917–922`) — сюда ложится подсказка для CLI-пути.
- Пресеты (`presets.yaml`): heroic, grim, romantic, fairytale. Паки: vale, drunk_dragon (`romance: откровенно`),
  dusk_academy (`намёки`, романтическая академия), test (не в git, untracked).
- Тесты пикера: `tests/unit/ui/test_ui_cli.py`, `test_cli_hero_describe.py`. `SMELLS_MAX = 206`; текущий счёт не мерил.

### Суть

При выборе пресета мира показать строку «<Пресету> лучше подходит <имя пака> — <id>», если у пресета есть «свой» пак и
текущий пак — не он. Выбор не навязывать. Пресет без пака — без строки. Сюжет, тон, сейв не меняются.

### Разбор (точки входа)

1. TUI-пикер пресета (после героя).
2. `--simple` — тот же `choose_number`, текст подсказки должен попасть и туда.
3. `--preset X` из командной строки — меню нет, подсказка только в заметках старта.
4. `--hero` / `--hero-describe` без `--preset` — меню пресета **не показывается вовсе** (`cli.py:855–861`, ветка `else`
   только при интерактивном герое): пресет = как в паке, подсказки нет. Пропущенная точка, решить явно (В6).
5. `--replay` — пресет не спрашивается; подсказка не нужна, но и не должна менять вывод повтора.
6. `--world` (продолжение) и merge пака в мир — пресет не выбирается, вне объёма.
7. `--import` — новый пак без связи с пресетом; вне объёма (или поле — В7).

### Оценка

**S при В1а, В2а, В3а** (≈ 0,6 млн по шкале R5). Поле + строка в `preset_label`/заметках + тесты пикера (TUI, simple,
`--preset`, пресет без пака, пак совпадает). При В2б или В3б — M, это уже другая партия.

### Риски

1. **Подмена смысла `manifest.preset`.** Роадмап считает его меткой «подходит», код — тоном по умолчанию. Если взять В1б
   молча, dusk_academy поменяет тон на старте без решения.
2. **Подсказка после героя** бесполезна без перезапуска; игрок может потерять выбранного героя, если поймёт её
   как «смени пак сейчас». Текст должен говорить «для нового мира».
3. **Соответствия пресет → пак** — контентное решение проектировщика, не разработки.
4. smells: лимит 206, счёт перед планом снять.
