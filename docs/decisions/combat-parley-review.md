# Переговоры в бою: отличия реализации от плана (kaban, 2026-10-06)

План: docs/COMBAT-PARLEY-PLAN.md; ответы проектировщика -- все 10 рекомендаций.

## Отличия и уточнения
1. Меню: вместо подменю «навык × исход» -- плоские пункты `parley:<цель>:<навык>:<исход>` (kind `parley`, цена action) для
   трёх пар: intimidation-surrender, persuasion-defect, deception-flee; показываются только если `check_request` пропускает
   (СЛ и «помеха» -- в подписи). Остальные пары -- через `PlayerAction.parley`. Подменю TUI -- BACKLOG 19.
2. R5: сдавшийся остаётся целью атак героя (`attack_targets`, `cast.TARGETABLE` для заклинаний цели и площадей); урон до 0 HP
   убивает, статус `surrendered` сам не снимается. EngineTactics сдавшихся не выбирает (`is_capable` False).
3. Ключевой NPC (`npc.key`): defect отклоняется (`key_npc_cannot_defect`), прочие исходы +5 к СЛ.
4. `immune_types` по умолчанию: construct, ooze, plant; нежить целиком не исключена (В4): Инт ≤ 3 отсекает зомби.
5. Группа цели для «потерь» считается по `group_id`; перешедший меняет `group_id` на группу героя, потерей прежней
   группы не считается.
6. Метки на существе: `parley_tried`, `wavering`, `parley_defected`, `parley_offended` (flag), `parley_advantage`
   (modifier, консьюмится при атаке по герою, снимается в конце хода цели). Убираются в `finish_combat`.
7. После боя: `combat_flow.settle_parley(bundle, cfg)` (зовётся из game/turn.py перед `finish_combat`): именованный NPC
   сдался +10, перешёл +20, оскорблён -10 к отношению, суммарно в пределах `[attitude] per_scene` (шаг `step` не применяется).
   XP: сдавшиеся и перебежчики считаются побеждёнными.
8. Рассказчик: правила в narrator_rules.md (parley вместо improvise, реплика по исходу из лога); инструментов в
   combat_narrate не добавлено.
9. `rules.checks.skill_check` получил `base_adv` и `base_adv_label` (R3 закрыт).

Замечания:
1. (средне) Добыча с живого перебежчика -- combat_flow.finish_combat: `p.ref in defected` кладёт monster_id в

2. (средне) Перебежчик-лидер -- parley.apply_defect: `state.groups[old].leader_id` остаётся на перебежчике,

   `defeat_group_id`, если это была его группа. Предложение: в parley_dc считать лидера выбывшим, если он

3. (мелко) parley.lose_turn в engine.step пропускает ход до start_turn: эффекты с `end_of_turn` на колеблющемся

4. (мелко) settle_parley: приоритеты delta через перезапись (offended > defected > surrendered) неочевидны;

6. Правила рассказчика (narrator_rules.md:36) -- по делу; стоит одной фразой сказать, что повтор по той же

## Правки по ревью mama-kaban
1. `LastCombat.defeated` (лут) без перебежчиков; XP за них начисляется (`defeated + turned`).
2. Лидер группы, сменивший `group_id` (перебежчик), считается выбывшим: в `parley_dc` (надбавка «лидер выбыл»), в
   `downed.ask_leader` (его не спрашивают о намерении) и в `defeat.creditor_of` (кредитором не бывает).
3. Колеблющийся: эффекты начала хода (горение, лозы) срабатывают -- `lose_turn` проверяется после `start_turn`,
   пропускается только действие хода (`run_controller`). Если цель в этот ход упала, метка остаётся до конца боя и
   снимается в `finish_combat`.
4. В `settle_parley` описан приоритет исходов (оскорблён > перешёл > сдался; на деле они взаимоисключающи).
5. narrator_rules: повторная попытка по той же цели будет отклонена.
