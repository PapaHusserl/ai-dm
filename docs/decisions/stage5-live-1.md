# Этап 5, живой прогон 1 (2026-10-06): замечания и решения проектировщика

1. Нет разделителя между сценами в ленте TUI → линия с названием сцены (`─── <сцена> ───`).
2. Панели «Бой» и «Броски» слишком маленькие → правая колонка шире, «Бой» и «Броски» выше за счёт листа героя.
3. Не сменить модель на Gemini: окно /model показывает список, но выбрать нельзя → в окне /model модель рассказчика выбирается
   (клик/цифра/Enter), выбор идёт через `set_narrator`, результат строкой в ленту; Esc — закрыть без смены.
4. /abilities показывает только первое предложение описания (gist, решение этапа 3) → полное описание с переносом
   в обоих режимах; так же для /spells и черт. Правка ожиданий простого режима — сознательная.
5. В бою не видно заклинаний Опутывающий удар и Туманный шаг. Опутывающий удар без механики боя (BACKLOG, «Заклинания без
   механики боя»), Туманного шага нет в контенте и в листе героя. Решение: механику — в бэклог, этап 5 закрывать без неё;
   в меню боя показывать подготовленные заклинания без механики серыми с пометкой «пока недоступно в бою» (не выбираются).
6. Панель «Бой» не прокручивается, варианты действий не видны → «Бой» прокручиваемый; варианты действий всегда видны
   (не обрезаются панелью).
7. Лента — сплошной текст, неудобно читать → разделение ходов: реплика игрока выделена цветом («▸ Ты: …»), рассказ мастера
   в рамке с отступами, между ходами орнамент. Только TUI (простой режим без изменений).
8. Ход боя — не в ленте, а сбоку: весь лог боя (атаки, урон, эффекты) — в панели «Ход боя» с прокруткой; в ленте только
   рассказ мастера и реплики игрока. Только TUI.
9. ASCII-рисунки нужны (пересмотр Q2/В7): локации (при входе в место), монстры (начало боя), заставка и события (титул,
   победа, смерть, новый уровень). Готовые рисунки в контенте, не генерация LLM. Отдельная партия P6 с планом папы-кабана.
10. Автодополнение команд в поле ввода TUI: при вводе «/…» подсказка имени команды из HELP (Tab/→ — принять).
11. /spells в TUI — окно выбора заклинания; выбор = каст. В бою: выбирается соответствующий пункт меню действий (как цифрой);
    заклинание без механики/без ячейки — невыбираемое с пометкой. Вне боя: ход игрока «Применяю заклинание «<Название>».»
    отправляется мастеру (как обычная реплика). Esc — закрыть без каста. Простой режим: /spells как сейчас (список).
