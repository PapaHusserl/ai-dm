### Проверка по вопросам
- **hard_exit**: вызывается после `super().run_async()`, т.е. после остановки драйвера Textual — терминал восстановлен.
  `after_exit()` (а значит `session.finish()`/автосейв) не вызывается, процесс умирает раньше; тест подтверждает, что слотов нет.
  `turn()` не делает `call_from_thread` при `abandon`. Гонка «ход закончился между двумя Ctrl+C» безопасна: `after_exit` по
  `abandon` всё равно 130.
- **stale_offer**: `recent_turns[-1].requests` сохраняется (миграция m0002), так что продолжение мира и `/load` дают верный
  ответ. Сбой хода — в `recent_turns` не пишется, но тогда открыт `pending` → ранний `False`, меню 2.2 показывается. Ход-команда
  (`/help` и т.п.) идёт с `refresh=False` и `menu` не шлёт. Отклонённый `offer_choices` в `requests` не попадает — список
  не покажется, это правильно. Ошибок не нашла.

### Правки (не блокеры)
1. `AiDmApp.run_async` — перед `hard_exit` сбрасывается только `sys.stdout`; заметки (`notes`) и логи идут в stderr —
   добавить `sys.stderr.flush()`. `os._exit` также пропускает atexit/flush журнала: если поток хода в этот момент пишет журнал,
   хвост может оборваться — это допустимо (журнал восстанавливается по незавершённому ходу), но стоит одной строкой
   в комментарии/ARCHITECTURE F4.
2. **Enter с цифрой при скрытых вариантах** (`on_input_submitted` → `session.submit("2")` → старый `offered_choices`):
   на экране вариантов нет, а «2»+Enter уходит как старый вариант. Это не нарушает букву решения 6 (game и простой режим
   не меняем, горячая цифра правильно выключена через `choices.display`), но расходится с его смыслом: скрытое на экране
   остаётся выбираемым. В TUI без правки game не закрыть — в бэклог, вместе с уже записанным хвостом «offered_choices не
   сбрасываются» (сброс в `GameApp.handle` закроет оба случая). Тест-фиксацию поведения можно добавить сейчас.
3. `vulture_allowlist.py`: имена глобальные (`on_click`, `action_close`, `closing`) — скроют такие же неиспользуемые имена в
   любом модуле. Для API Textual это принятый в P1 способ, приемлемо; `closing` — атрибут только для тестов, так и подписать.
