# Партия В «трофеи с тел»: ревью и решения

## Решения проектировщика (2026-10-07)
1. Качество показывается приставкой везде (/inv, «Получено», контекст мастера): «Поношенный скимитар» вместо «Скимитар (поношенное)».
2. Выбитое у монстра оружие (в т.ч. схваченное сразу, grab) получает качество и цену трофея по ПО врага (trophy_cost); у босса — полная цена.

## Отклонения от плана (kaban)
- body_gear(bodies, registry, cfg) без hero; квестовые — отдельная quest_gear(world, refs).
- gear считается в combat/end.py::settle_ground (движка в finish_combat нет), CombatState.gear — схема сейва v6 обновлена.
- gold_loot/loot_gear вынесены в protocol/handlers/loot_gear.py (make smells).
- WINDOW мока 20500 оставлен.
3. Цена трофеев (SRD-предметов) в /inv не показывается — отложено до торговли (BACKLOG 23).
4. По ревью: без денег на телах лог показывает только вещи; NPC-участник без статблока — «тело» для квестовых предметов.

## Ревью мамы-кабана
Пп. 1–6, 9 исправлены: лог денег только при выдаче >0; отказ при `looted and (gear_looted or not gear)`; квестовые с
участников без monster_id; is_boss через groups.get; bool(named); лог «Возвращён предмет» при обыске; из контекста
мастера убран мёртвый gear_looted (last_combat = {"gear": [...]}). Пп. 7–8 не правились (BACKLOG 16).
Оркестратор: is_boss/weapon_price/enemy_gear вынесены в combat/trophies.py (сложность disarm.py — make smells).
