### Находки
- **Ф1 (UX, Т60).** При перегрузке 3.8-flash меню ошибки появляется через ≈ 4,5 мин (ход 23: таймаут 92 с, 504 89 с,
  504 89 с, 503) — следствие Q3(б): полные повторы рассказчика без авто-переключения. Варианты: меню сразу после
  первого 504/таймаута; меньше повторов у рассказчика. **Решение проектировщика — открыто.** → 19ф (`retry_timeouts`)
- **Ф2 (ТВ/бой).** Ход 5 закончился «*(В этот момент начинается бой!)*» без `start_combat` (бой начался на ходу 6).
  Ходы 9–10 (бой / выход из боя) кончаются вопросом без меню — проверка `choices_missing` в бою выключена по плану;
  если на экране ходы выглядели односторонними — кандидат: проверять ход, на котором бой закончился.
- **Ф3 (ТМ).** Ручной репорт `issues/20261015T170350-t21-manual` — «повторы предыдущих сообщений» (ход 21) — материал
  для #20 ТМ (T6), не разобран.

- **Ф4 (прогон).** Рассказчик (flash-lite, argon) не выводит заказанных врагов: за 40 ходов vale — два боя (ход 6
  скелет в подвале, ход 32), гоблинов/нежить из блоков В–Г по просьбе получить не удалось. Боевые пункты нельзя
  прогнать без детерминированного способа начать бой с нужным составом. Кандидат: отладочная команда старта боя
  с заданными монстрами (для прогонов) — **решение проектировщика открыто**.
