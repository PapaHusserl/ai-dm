### Низкий приоритет
6. `improvise.py`: `EFFECT_WORDS.get(effect) or engine.registry.get("condition", effect).name` — для любого эффекта вне словаря идёт в
   реестр состояний; безопасно только потому, что `check_request` уже отсёк неизвестные. Допустимо; можно явнее
   `... if effect == "prone" else EFFECT_WORDS[effect]`. Косметика.
7. `roll_pipeline.py`: `tag and source_label(registry, tag)` — идиома «and» для None. Работает (tag — None или feat_id), стиль соседнего
   кода обычно `if`. Без правки.
8. linux_check.sh, надёжность:
   - не запускался — приёмочный пункт формально не закрыт (см. вопрос 1);
   - `pip install -q uv` без версии — плавающий uv; `uv sync` без `--frozen`/`--locked` может переразрешить зависимости вместо
     uv.lock. Предложение: `uv sync --locked -q`;
   - исключения `--exclude=./saves` и т.п. корректны для `tar -C /src ... .`; `.env*` варианты (`.env.local`) не исключены —
     если такие бывают, добавить `--exclude='./.env*'`;
   - ключи: `docker run` без `-e`/`--env-file`, так что ключи не попадают, кроме как через файлы в репо — покрыто исключением .env;
     сеть в контейнере есть (нужна для uv sync), живые вызовы в тестах и так замоканы;
   - `sh` вместо `bash` и `set -eu` — ок; проверки «docker не найден/демон не запущен» нет, ошибка docker будет понятной сама.
