### Что есть в коде (факты)

- CLI — плоский `argparse` без подкоманд (`ui/cli.py:79–105`). `ai-dm import <файл>` в нём не разбирается: нужен либо
  subparsers (меняет разбор всех текущих флагов), либо флаг. Строка роадмапа задаёт форму `ai-dm import <файл> --campaign`.
- Загрузчик: `campaign/loader.py:311` `load_pack`. Обязательны `campaign.yaml` и `world.md`; списки `npcs/factions/
  pantheon/locations/events.yaml` — по `LIST_FILES` (стр. 35), отсутствие файла допустимо (у `vale` нет factions/pantheon/
  truths). **Нужен ≥1 пресет героя** (стр. 335–336) — пак из import без `heroes/` не загрузится. Это BACKLOG 16 (в);
  в Б2 (В11а) оставлено «не трогать».
- `CampaignManifest` (`campaign/models.py:66`, `extra="forbid"`): обязательны `id`, `name`, `version`, `start.date`,
  `start.hero_location` (должна быть в locations, `check_manifest` стр. 242). Модель должна выдать корректную дату под
  календарь пака (или без календаря).
- Ссылки сущностей проверяет `check_pack_refs` (стр. 184) — триггеры/условия ссылаются на существующие id (ТЗ 4: «движок
  проверяет, что ссылки указывают на существующие id»).
- **Уникальность 5.3 в `load_pack` не проверяется.** Она в `campaign/uniqueness.py:30` `collect_conflicts(world, heroes,
  pack)` и вызывается при создании мира (`campaign/build.py:169`) и при слиянии пака в идущий мир (`campaign/merge.py:41`).
  Значит «пак грузится без ошибок 5.3» сейчас = `load_pack` + отдельный вызов `collect_conflicts` с пустым миром и
  героем; конфликты с именем героя всплывут только при старте.
- `CAMPAIGNS_DIR` = корень репозитория `/campaigns` (`loader.py:32`); у CLI есть `setup.campaigns_dir`.
- Роли модели: `narrator`, `world`, `summarizer` (`config/app.py:152`). Режимы протокола героя — `HERO_MODES`
  (`protocol/requests.py:818`). Роли/режима/промпта для import нет (`master/prompts/` — 5 правил, import нет).
- Журнал и `/cost` живут в мире. У import мира нет — некуда писать вызов и цену (у героя Б1 журнал есть, т.к. мир
  создаётся сразу после).
- П. 30, мутанты: `ui/cli.py:433` `campaign_registry` и `loader.py:231` `pack_npc_trade` (ветка `None`) вызываются в
  replay/continue (`cli.py:476–479`, `635–654`). Ветка «у сейва другой campaign_id, чем подсмотренный» (стр. 646–649)
  тестовым миром не покрыта.
- `tests/scenarios/test_stage6b_done.py` — герой на лету и пошаговый (Б1/Б2); import-теста нет. Критерий stage6 В1а:
  «import на моке даёт пак, который грузится без ошибок 5.3».
- `--replay-report` есть (6а P2, коды 0/1/2). Живой прогон «`/report` → `--replay-report` на реальной модели» —
  пользователя, во время игры (BACKLOG 30), кодом не закрывается.

### Суть

Команда вне игры: текстовая выжимка → один или несколько вызовов модели → файлы нового пака в `campaigns/<id>/` →
проверка тем же загрузчиком → пользователь правит руками. Плюс хвосты п. 30 (мутанты, живой replay) и закрытие 6б
тестом `test_stage6b_done`.

### Короткое ТЗ (при рекомендованных ответах)

**Входит.**
1. Команда import (форма — В3): `<файл>`, `--campaign <id>`, `--mock`, модель по конфигу. Каталог существует — отказ,
   ничего не пишется.
2. Режим протокола import, промпт `prompts/import_rules.md` (+ справочник id реестра, как `sheet_reference_block`),
   strict-инструмент со схемой пака (В5), роль по В6.
3. Запись файлов пака (состав — В2); проверка `load_pack` + `collect_conflicts` с пустым миром; ошибки → повтор модели
   по В4; итоговый отчёт: путь, файлы, ошибки/предупреждения строками «файл: поле: что не так».
4. Пак без пресетов героя — по В1.
5. Журнал и цена вызова — по В7.
6. П. 30: тестовый мир с другим `campaign_id` → мутанты `campaign_registry`/`pack_npc_trade` (ветка `None`).
7. `test_stage6b_done`: мок-выжимка → пак записан → `load_pack` без ошибок → новый мир из него → ход; повторный import
   в тот же id — отказ, файлы целы; невалидный ответ модели → по В4.

**Не входит.** Существа (BACKLOG 2 → Ж4); `heroes/`, `start/`, `events.yaml`, `content/` (если В2а); import внутрь
идущего мира; правка существующего пака.

**Готово, когда.** Пункт 7 зелёный; make smells ≤ лимита, make dead чисто, mutmut по новым функциям; живой прогон по В10.

### Объём

### Риски

1. **Пресет героя обязателен** — без решения В1 критерий «пак грузится» невыполним.
2. **5.3 не в загрузчике** — легко принять «`load_pack` прошёл» за «5.3 проверена». Подмена.
3. **Схема пака большая** (`CampaignManifest` с календарём, mortality, natural_events, nudge, tone; NPC с триггерами) —
   strict-схема инструмента раздуется, модель будет ошибаться в датах и ссылках. Повторы — цена.
4. **smells 204/205** — запас 1.
5. **Нет мира — нет журнала:** без В7 вызов import не попадёт в `/cost` и не воспроизводится.
6. **Длина выжимки** — сессия Антигравити может не влезть в окно; лимит входа не задан.
