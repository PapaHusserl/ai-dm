# Партия А (кастомные предметы) — ревью и решения

## Решения проектировщика (2026-10-07)
1. Вес кастомного предмета в сейве — `CustomItem.weight_centilb: int | None` (сотые доли фунта; инвариант «нет float в сейве»).
   Запрос `give_custom_item.weight_lb` — float, обработчик `round(x*100)`; показ (партия Б) делит на 100.
2. Поля `LastCombat.gear_looted`, `ItemHolder.since_s`, `CustomItem.weight_centilb`, `CustomItem.created_s` — в vulture_allowlist
   до партий Б/В (убрать, когда начнут читаться).
3. Лог «Отобрано: <предмет> — у <label>» при rob/capture — сделать в правках партии А (`notes` в `DefeatResult`).
4. `give_item` кастомного предмета с держателем — количество ограничено `holder.qty`.
5. Дедуп `give_custom_item` по имени не обновляет description/weight/quest существующего предмета (защита квестовых).

## Отступления kaban от плана
- `give_custom_item` добавлен в `MODE_TOOLS["explore"]` (иначе инструмент не виден модели).
- `protocol/hints.py`: item_ids не перечисляет кастомные (source == "world").
6. Повторная выдача (`give_custom_item` дедуп) предмета, который уже у героя: квестовый — отказ с подсказкой мастеру
   «уже у героя»; обычный кастомный — можно ещё копии.
7. При capture несюжетные кастомные тоже уходят в «тайник логова» (держатель location=lair), а не очищаются (изменение разд. 5 плана).
