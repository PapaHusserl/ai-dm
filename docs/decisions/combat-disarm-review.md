# Отбор оружия: отличия реализации от плана (kaban, 2026-10-06)

План: docs/COMBAT-DISARM-PLAN.md; ответы проектировщика -- В1–В11 по рекомендациям.

## Отличия и уточнения
1. В2: только вариант «бросок атаки против проверки цели»; режим `[disarm].mode = "save"` не делался (в конфиге нет).
   Порядок: цель бросает проверку (Атлетика/Акробатика героя, лучший мод. Сил/Лов монстра), её итог -- КД для броска
   атаки героя (строка «проверка цели»).
2. Опция по строке на оружие цели (`disarm:<цель>:<оружие>`, params `target`, `weapon_id`), а не одна на цель (R2).
3. Бросок -- первая ближняя атака героя (оружие в руке, затем из инвентаря, затем безоружный; подручное не берётся).
   «Выхватить в руки» (grab) -- когда этой атакой оказался безоружный удар и рука свободна (двуручное при щите не берётся
   в руку, остаётся в инвентаре).
4. В9: монстр обезоруживает только с тегом `disarmer` (опция есть только у него, `EngineTactics` её берёт); `enemy_chance`
   не делался (тактика без бросков).
5. ИИ: `pickup` монстра -- первым делом, только в своей зоне (шаг к оружию в соседней зоне не делался); авто-герой
   подбирает, если рука пуста.
6. Безоружный удар монстра: если после отбора нет ни одной атаки (естественные атаки остаются, кулак не добавляется) и
   тип в `[disarm].unarmed_types` (по умолчанию `humanoid`, `fey` -- гоблины в SRD fey); бонус = мод. Сил +
   `[disarm].unarmed_proficiency` (2, функции БМ по CR в коде нет), урон 1 + Сил, не ниже 0.
7. Монстр подбирает оружие, чьё действие у него отобрано (свое или такое же чужое); флаг снимается.
8. В10: `parley.apply_surrender` вызывает `disarm.surrender_drop` (оружие на землю). −2 к СЛ переговоров обезоруженному --
   `[parley].disarmed_bonus` (в `parley_dc`).
9. Конец боя (`end.settle_ground`): победа/ended_by_master при живом герое -- выбитое в инвентарь (своё -- владельцу,
   иначе первому живому герою); иначе предметы героев теряются (лог), чужие исчезают; метки `disarmed` снимаются.
10. Карта боя: строка «На земле: …» (`battle_map.ground_line`, `battle_map_lines(..., registry=None)`).
11. Рассказчик: строка в narrator_rules.md (disarm и pickup -- из `combat.options`; improvise disarm -- нестандартные способы).
12. Схема сейва: новые поля `CombatState.ground_items`, `TurnState.free_interaction`, `GroundItem` -- с умолчаниями, версия 5.

## Мутации (kaban-doeba, 2026-10-06)
`make mutate MOD="ai_dm.combat.disarm ai_dm.combat.end"` с TESTS на тесты партии: после разбора 8 выживших в новом коде,
все эквивалентные. `settle_ground` — 0 выживших. Модули `available`, `attack`, `controllers`, `battle_map` в этот прогон не
входили (лимит времени; изменённые функции покрыты поведенческими тестами, `make cov` 95,92%).

| Мутант | Что изменено | Почему эквивалентен |
|---|---|---|
| disarm.strike_info 5 | `and` -> `or` в выборе ближней атаки | безоружный удар всегда стоит в `attacks_of` перед «improvised», первая ближняя атака та же |
| disarm.strike_info 10, 11 | строка `"improvised"` испорчена | то же |
| disarm.target_check 1 | `skill = None` -> `""` | у монстра `skill` в запросе не влияет на бросок |
| disarm.target_check 54 | убран `actor_id` | в `roll` для проверки не используется |
| disarm.target_check 57 | убран `bonus=` | бонус считается из `bonus_parts`, `bonus` дублирует |
| disarm.target_check 69, 73 | `modifiers=None` / не передан | реестр модификаторов по умолчанию даёт тот же результат (отравленный всё равно бросает с помехой) |

Остальные выжившие в `end.py` (`set_outcome`, `conclude` — концентрация, скрытность, подпись исхода) — старый код, не новые
строки партии; в BACKLOG.

## Ревью mama-kaban (2026-10-06)
По важности:
1. **Ничья в состязании** (`disarm.perform`): `roll_attack(..., check.total)` трактует итог проверки как КД, при равенстве
   засчитывается попадание. По правилам состязаний ничья оставляет положение как было -- цель удерживает оружие.
   Предложение: передавать `check.total + 1` (подпись «проверка цели» с итогом проверки) или сравнивать итог атаки с
   `check.total` строго; тест на ничью (фиксированный rng).
2. **ИИ зацикливается на disarm** (`EngineTactics.pick_special`): монстр с `disarmer` ставит disarm выше multiattack и
   атак, пока у цели есть оружие. Герой подбирает выбитое свободным взаимодействием -- босс каждый ход только
   обезоруживает и не наносит урона. Предложение: disarm только если цель ещё не обезоруживалась этим монстром
   (флаг/метка на бой) или только когда multiattack недоступна; тест «два хода подряд -- второй ход атака».
3. **Трофеи при победе** (`end.settle_ground`): чужое оружие (owner -- монстр) уходит первому живому герою. Проверить,
   не дублирует ли это обычную добычу с монстра (лут после боя) -- иначе меч гоблина выдаётся дважды. Поражение:
   своё оружие героя теряется насовсем (уже удалено `strip_weapon`) -- по плану, но в лог/рассказчику стоит явно.
4. **KeyError в переговорах** (`parley.menu_entries` перебирает всех участников, `engine.monster` у героя на стороне
   врагов): старый баг, `disarm` его не трогает, но `parley_dc` теперь зовёт ещё `has_flag`. В BACKLOG с тестом.
5. **Оружие из рюкзака** (`strike_info`): по SRD 5.2 достать одно оружие -- часть атаки, так что бить копьём из рюкзака
   допустимо. Но следствие: «выхватить в руки» (grab) срабатывает только у героя без единого оружия. Оставить, описать
   в отличии №3 явно (уже почти описано).
6. **Монстр с флагом и только естественными атаками** -- корректно: weapon_id у когтей None, `result` не пуст, кулак не
   добавляется. Старый флаг без weapon_id (`all_lost`) -- тоже без кулака, если есть естественные. Ок.
7. **Схема v5**: новые поля с умолчаниями, старые сейвы грузятся; `lost_weapons` понимает старый флаг без weapon_id. Ок.
8. **Тесты не хватает** (мутации не гонялись): `available.disarm_options` -- цель в другой зоне/неспособная, нет
   `may_disarm`; суффикс «(ещё N из 2)» для disarm; `pickup_options` -- cost free/action и пусто без обоих;
   `controllers.pick_special` -- герой не берёт pickup/disarm, порядок escape > pickup > disarm;
   `AutoHeroController` pickup только при пустой руке; `attack.monster_unarmed` -- тип не из `unarmed_types`, урон
   не ниже 0; `multiattack` пропуск отключённого шага; `battle_map.ground_line` при `registry=None`. Прогнать
   `make mutate MOD="ai_dm.combat.available ai_dm.combat.controllers"` хотя бы по новым функциям.

Мелочь: в `disarm.perform` условие `engine.heroes[ref]` держится только на том, что у монстров `weapon_id` в AttackInfo
всегда None -- добавить `engine.is_hero(ref) and` для ясности.

**Вердикт:** нужны правки (п. 1, 2; п. 3 проверить).

## Правки по ревью (kaban, 2026-10-06)
1. Ничья: КД броска атаки = итог проверки цели + 1, цель удерживает оружие.
2. `EngineTactics.pick_special`: disarm монстра -- один раз за бой (по метке `disarm_used` на монстре, снимается в conclude), затем атаки.
3. Двойной выдачи нет: `rules/loot.py` выдаёт только деньги, предметов с врагов нет; потеря оружия героя при поражении --
   строка «остался на поле боя» в логе боя (его читает рассказчик).
4. `parley.mind_problem`: участник без записи монстра (герой на стороне врагов) -- `not_sentient`, KeyError нет.
5. Следствие отличия №3: «выхватить в руки» срабатывает только у героя вообще без оружия (иначе бьёт оружием из рюкзака).
9. `disarm.perform`: проверка `engine.is_hero(ref) and` перед доставанием оружия.
