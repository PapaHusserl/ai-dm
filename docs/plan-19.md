# Шаг 19. Переговоры в бою: «ссорится» и мораль группы (BACKLOG 19)

Исходная партия — docs/plan-combat-parley.md. План — папа-кабан (ниже).

## Решения

Проектировщик, 2026-10-20 (груминг: свинопас + кабан-свекровь):

1. Цель поссорившегося — союзник по боевой группе (`group_id` = группа мира); если в группе никого нет — любой боец
   своей стороны.
2. Подходящей цели в досягаемости нет — поссорившийся идёт к цели (и бьёт, если дотянется).
3. Ссора на один ход (`turncoat_once`), пострадавший в ответ не бьёт.
4. СЛ «ссорится» — надбавка +2; в меню не добавлять, только фразой.
5. Мораль группы (`spread_morale`):
   - а) запускает только сильный успех (10+ сверх СЛ или натуральная 20);
   - б) затрагивает каждого в группе с HP ≤ 50 %, без броска;
   - в) распространяются только «сдаться» и «бежать», не «перейти»;
   - г) флаг включён по умолчанию.
6. Подменю TUI «навык × исход» — не в этом шаге, отдельным новым пунктом BACKLOG; BACKLOG 19 закрывается целиком.

Проектировщик, 2026-10-20 (открытые вопросы плана папы-кабана):

7. Обман «ссорится» по цели, у которой на её стороне никого нет, — отказ `no_one_to_quarrel` до броска, действие
   не тратится.
8. Мораль не задевает раненых, кто не слышит переговоров (`mind_problem`: Инт ≤ 3, конструкт и т. п.).

Проектировщик, 2026-10-20 (по аудиту кабана-свекрови):

9. Лог морали — «… тоже сдаётся» / «… тоже уходит» (как в плане), не обычные строки `apply_*`.
10. Мораль требует только разумности (`sentient`), слышимость зоны не проверяется — решение 8 узко, как сделано.

## План (папа-кабан, 2026-10-20)

**Задача:** исход Обмана `quarrel` (цель один свой ход бьёт союзника) и мораль группы при сильном успехе.

**Правило (первым пунктом аппрува):**
- `ALLOWED["deception"]`: было `("flee", "waver")` → станет `("flee", "waver", "quarrel")`.
- Цели атаки участника: было `p.side != side` (`attack_targets`, `EngineTactics.enemies`) → станет: у метки
  `quarreling` — `quarrel_targets(engine, ref)` = боеспособные с тем же `group_id` (кроме себя), если таких нет —
  боеспособные той же `side`; без метки — как было.
- Исход переговоров: было `if result.outcome == "success": return APPLY[outcome](...)` → станет: то же, плюс
  `strong = result.total - dc >= cfg.strong_margin or result.natural == 20` и при
  `cfg.spread_morale and strong and outcome in ("surrender", "flee")` — тот же `APPLY[outcome]` каждому из группы
  цели: `status == "active"`, боеспособен, `hp_current * 2 <= hp_max`, без броска. Натуральная 20 при провале
  (total < СЛ) морали не даёт — сначала успех.
- `spread_morale`: было `False` → станет `True` (settings.py и defaults.toml).

**Поведение:** меняется — в бою Обман фразой «он вас предаст» даёт `quarrel` (в меню нет); при сильном успехе
«сдайтесь/уходите» с группой цели уходят/сдаются раненые (≤ 50 % HP). Сейв не меняется (метка — строка в
`ActiveEffect`, миграции нет).
**Вне репо:** нет.

**Тестовые сценарии (kaban-doeba):**
- deception+quarrel проходит проверку (заменить `test_quarrel_is_not_in_this_batch` :367 и `unknown_outcome` :867);
  intimidation/persuasion+quarrel → `outcome_not_allowed`.
- СЛ quarrel = СЛ waver-без-бонуса + 2 (слагаемое «ссора +2» в логе).
- Успех quarrel → метка `quarreling` с `end_of_turn`/owner=цель; на ходу цели атака по союзнику из её группы в
  зоне (самый слабый); после её хода метки нет, следующий ход — снова по героям.
- В группе цели никого, на стороне есть другая группа → бьёт бойца другой группы своей стороны.
- Союзник в другой зоне, дальней атаки нет → цель шагает к нему (решение 2); с дальней — стреляет.
- Пострадавший на своём ходу бьёт героя, не поссорившегося (решение 3).
- У поссорившегося нет толчка/особого против героя в этот ход; мультиатака — все удары по союзникам.
- Поссорившийся с меткой не входит в опции атаки героя иначе, чем раньше (метка влияет только на его собственные
  цели).
- Мораль: surrender, итог ≥ СЛ+10 → раненые (HP ≤ 50 %) из группы сдаются, целые — нет, из другой группы — нет;
  итог СЛ+9 → морали нет; натуральная 20 с успехом → мораль; натуральная 20 с провалом → ничего.
- Мораль при flee — уходят; при defect/waver/quarrel — нет; `spread_morale=false` — нет.
- Сдавшийся по морали роняет оружие (`surrender_drop`), попадает в выжившие/добычу как одиночный (game-тест).
- Бой кончается, если мораль сняла всех врагов (`victory`).
- Руками (ЖП4): Обман «он вас предаст» в бою → лог «ссорится», враг бьёт своего; «сдавайтесь» с большим броском
  по раненой группе → несколько сдались.

**Развилки и риски:**
- Цель ссоры среди союзников — по существующей тактике (`weakest` в своей зоне); отдельного правила нет.
- Риск R1: мораль закрывает бой одним действием — смягчено условием HP ≤ 50 % и флагом.
- Ветка «на стороне никого» недостижима, если отказать заранее (вопрос 1) — тогда `quarrel_targets` пустым
  на ходу не бывает, кроме гибели всех союзников между ходами → `end_turn` через `approach` (тест).
- Если у врага контроллер не `engine` — ссора не сработает (тактика только у `EngineTactics`); по `engine.py:137`
  враги — `engine`; kaban проверяет.

**Открытые вопросы:**
1. Обман «ссорится» по цели, у которой на её стороне больше никого нет (`parley.py:82` `history_problem`):
   (1) отказ `no_one_to_quarrel` до броска, действие не тратится; (2) бросок идёт, при успехе цель просто теряет
   ход. Рекомендую (1) — как прочие отказы, без пустого броска. Разблокирует партию 2; решает проектировщик.
2. Мораль задевает раненых, кто не слышит переговоров (Инт ≤ 3, конструкт/слизь/растение — `mind_problem`)?
   (1) нет, их пропускать; (2) да, всех. Рекомендую (1) — тот же порог, что у одиночной цели. Ключевой NPC
   (босс) сдаётся по морали как и одиночно (key запрещает только defect). Разблокирует партию 3; решает
   проектировщик.
