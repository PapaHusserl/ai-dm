# Шаг 96а — Экипировка и зелья из окна инвентаря (BACKLOG 96, часть без полей сейва)

Суть: игрок сам надевает/снимает доспех и щит, берёт оружие в основную и вторую руку, пьёт зелья — из окна `inv`.
Слоты одежды и украшений — 96б (М0/М0п), не здесь. План — папа-кабан (ниже).

## Решения

Проектировщик, 2026-10-19 (BACKLOG 96, NOTES.md): экипировка и приём зелий вне боя — из окна `inv`; деление 96а/96б.

Проектировщик, 2026-10-20 (груминг: свинопас + кабан-свекровь):
1. В бою — матрица SRD: доспех — нельзя; щит — тратит действие; оружие — бесплатно (взаимодействие с предметом).
2. Смена оружия/щита в бою — из окна `inv`, не пунктом боевого меню.
3. Зелья из `inv` вне боя — все с эффектом: лечебные (`use_item`) и эликсиры (`drink_item`: `ac_bonus`, `resist`).
4. Рассказчик узнаёт о действии из `inv` (выпил/надел/снял) в следующем ходе; лимит `consumables_per_scene` действует.
5. «Снять» — для всех слотов; TUI и простая UI (подкоманды `/inv`); только герой игрока, не спутники;
   одежда без действий до 96б.
6. Надевание/снятие доспеха вне боя двигает часы мира по SRD (минуты по типу доспеха).

Проектировщик, 2026-10-20 (развилки плана папы-кабана, по одной):
7. Развилка 1 — двуручное/щит при занятой руке: вне боя мешающее снимается само (строка «снял …»), в бою — отказ
   «сначала сними …».
8. Развилка 2 — строка для рассказчика: буфер в `Game` + префикс к `player_input` следующего хода, без полей сейва.
9. Развилка 3 — выбор в окне `inv` в бою — шаг хода с вызовом рассказчика, как номер меню.
10. Развилка 4 — щит вне боя двигает часы на 1 минуту (против рекомендации папы «без сдвига»).
11. Развилка 5 — в лимит `consumables_per_scene` идут только лечебные зелья, эликсиры нет (как сейчас).

Проектировщик, 2026-10-20 (по аудиту свекрови П1 — решения кабана по ходу приняты пакетом):
12. Скрытые боевые варианты `equip`/`unequip` — после `end_turn`, видимые номера меню не меняются.
13. Смена доспеха двигает часы на снятие старого + надевание нового; автоснятый щит — тоже 1 минута.
14. Заметка рассказчику служебная, без согласования рода («надел «Кольчуга»»).
15. Заметки из `inv` не цепляются к ходу номером в бою, ждут словесного хода (рассказчик может узнать после боя).
16. Сдвиг часов из `inv` гасит просроченную концентрацию; переход через полночь (`tick_days`, `close_scene_if_needed`,
    истечение эликсиров) не обрабатывается — пункт BACKLOG.
