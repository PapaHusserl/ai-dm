# Шаг 96а — Экипировка и зелья из окна инвентаря (BACKLOG 96, часть без полей сейва)

Суть: игрок сам надевает/снимает доспех и щит, берёт оружие в основную и вторую руку, пьёт зелья — из окна `inv`.
Слоты одежды и украшений — 96б (М0/М0п), не здесь. План — папа-кабан (ниже).

## Решения

Проектировщик, 2026-10-19 (BACKLOG 96, NOTES.md): экипировка и приём зелий вне боя — из окна `inv`; деление 96а/96б.

Проектировщик, 2026-10-20 (груминг: свинопас + кабан-свекровь):
1. В бою — матрица SRD: доспех — нельзя; щит — тратит действие; оружие — бесплатно (взаимодействие с предметом).
2. Смена оружия/щита в бою — из окна `inv`, не пунктом боевого меню.
3. Зелья из `inv` вне боя — все с эффектом: лечебные (`use_item`) и эликсиры (`drink_item`: `ac_bonus`, `resist`).
4. Рассказчик узнаёт о действии из `inv` (выпил/надел/снял) в следующем ходе; лимит `consumables_per_scene` действует.
5. «Снять» — для всех слотов; TUI и простая UI (подкоманды `/inv`); только герой игрока, не спутники;
   одежда без действий до 96б.
6. Надевание/снятие доспеха вне боя двигает часы мира по SRD (минуты по типу доспеха).

Проектировщик, 2026-10-20 (развилки плана папы-кабана, по одной):
7. Развилка 1 — двуручное/щит при занятой руке: вне боя мешающее снимается само (строка «снял …»), в бою — отказ
   «сначала сними …».
8. Развилка 2 — строка для рассказчика: буфер в `Game` + префикс к `player_input` следующего хода, без полей сейва.
9. Развилка 3 — выбор в окне `inv` в бою — шаг хода с вызовом рассказчика, как номер меню.
10. Развилка 4 — щит вне боя двигает часы на 1 минуту (против рекомендации папы «без сдвига»).
11. Развилка 5 — в лимит `consumables_per_scene` идут только лечебные зелья, эликсиры нет (как сейчас).

Проектировщик, 2026-10-20 (по аудиту свекрови П1 — решения кабана по ходу приняты пакетом):
12. Скрытые боевые варианты `equip`/`unequip` — после `end_turn`, видимые номера меню не меняются.
13. Смена доспеха двигает часы на снятие старого + надевание нового; автоснятый щит — тоже 1 минута.
14. Заметка рассказчику служебная, без согласования рода («надел «Кольчуга»»).
15. Заметки из `inv` не цепляются к ходу номером в бою, ждут словесного хода (рассказчик может узнать после боя).
16. Сдвиг часов из `inv` гасит просроченную концентрацию; переход через полночь (`tick_days`, `close_scene_if_needed`,
    истечение эликсиров) не обрабатывается — пункт BACKLOG.

## План (папа-кабан, 2026-10-20)

**Задача:** экипировка (надеть/снять/взять в руку) и зелья вне боя — подкомандами `/inv` (обе UI) и интерактивным
окном `inv` в TUI; в бою — смена оружия/щита по матрице SRD через то же окно.

**Правило (первым пунктом аппрува):**
- новое: в бою оружие в руку/из руки — `cost = "free" if turn.free_interaction else "action"` (как
  `combat/available.py:pickup_options`, стр. 407–412); щит надеть/снять — `cost = "action"` (Utilize, SRD 5.2);
  доспех — вариантов нет.
- новое: вне боя `world.clock.advance(ARMOR_MINUTES[category][on|off] * 60)`; SRD 5.2: лёгкий 1/1 мин,
  средний 5/1, тяжёлый 10/5; щит вне боя — без сдвига (действие = 6 с, развилка 4).
- было `equip`: двуручное при щите/оружии в левой → `InventoryError`; щит при двуручном → отказ
  (`rules/inventory.py:108`) → станет: по развилке 1 (оставить отказ или снимать мешающее).
- лимит зелий: было — только в обработчике `protocol/handlers/resources.py:use_item` (стр. 344:
  `left = consumables_per_scene - scene.consumables_used`, только для `heal`) → станет: та же формула через общую
  функцию, зовут обработчик и `/inv`; эликсиры, как и сейчас, лимитом не считаются (развилка 5).

**Поведение:** меняется — `/inv` без аргумента как был (справка); с подкомандой меняет героя; TUI `/inv` открывает
интерактивное окно вместо `TextModal`; в бою появляются (скрытые из меню) варианты смены оружия/щита.
**Вне ai-dm:** нет. **Поля сейва:** не нужны (см. развилку 2 — носитель строки для рассказчика выбран без поля).

**Тестовые сценарии (TDD):**
- `unequip(hero,"shield")` → слот None, предмет в инвентаре; пустой слот → `InventoryError`.
- вне боя `/inv надеть кольчуга` (heavy) → `armor` = кольчуга, часы +600 с; `снять` → +300 с; без владения → отказ, часы не двигаются.
- `/inv надеть кинжал левая` при щите → отказ (или снятие щита — по развилке 1); двуручное при щите — то же.
- один кинжал (qty 1) в `main_hand`, `надеть кинжал левая` → отказ.
- `/inv выпить зелье лечения` при `consumables_used == limit` → отказ, предмет цел; ниже лимита → +HP, счётчик +1;
  эликсир → эффект до hh:mm, счётчик не растёт; обработчик `use_item` даёт те же числа (регресс).
- следующий ход: `player_input` рассказчика содержит строку «надел/снял/выпил» ровно раз; после хода буфер пуст.
- бой: смена оружия при `free_interaction` → бесплатно, второй раз → тратит действие; щит → действие; без действия
  щит недоступен; доспех — вариантов нет; варианты `equip` нет в `turn_menu_lines`/`build_view`/`option_list`.
- `attack.perform`/`disarm` — регресс: бесплатная смена при атаке не сломана.
- зелья из `/inv` в бою → подсказка «в бою — меню, Использовать».
- Руками (ЖП4): TUI `/inv` → окно, Enter на щите → надет, КД в панели выросла; следующий ход рассказчик упоминает.

**Развилки (выбор за проектировщиком):**
1. Двуручное/щит при занятой руке: (а) отказ с подсказкой «сначала сними …» — как сейчас; (б) мешающее снимается
   само, строка «снял щит». Рекомендую (б) вне боя, (а) в бою (щит снимать — действие, неявная трата удивит). Видимое.
2. Носитель строки для рассказчика: (а) буфер в `Game` + префикс к `player_input` следующего хода (рекомендую: без
   полей сейва, сам ложится в `TurnRecord`; минус — выход до хода теряет строку, но состояние героя рассказчик видит);
   (б) отдельный `TurnRecord` с пустой narration (сохраняется, но второй `turn_seq` ломает поиски в
   `resources.py:584, 684, 810` и занимает окно `recent_turns`); (в) новое поле сессии — только М0, против 96а.
3. Окно в бою: те же клавиши, а выбор — шаг хода с вызовом рассказчика (как номер меню; дорого, но единообразно) —
   рекомендую; альтернатива — смена оружия без рассказчика до следующего шага (нужен свой путь в движок боя).
4. Щит вне боя: без сдвига часов (рекомендую; SRD — действие) или 1 мин для единообразия.
5. Лимит `consumables_per_scene` и эликсиры: как сейчас — только лечебные (рекомендую, решение 4 о лимите не
   расширяет его), или считать и эликсиры.
**Риски:** сдвиг часов вне хода обходит `close_scene_if_needed`/`tick_days` (минуты — переход полуночи редок;
проверить на границе суток); фильтр вариантов в `option_list` — иначе рассказчик боя позовёт `player_action` на смену
оружия (как в 106); «один предмет в двух руках» — существующая дыра `equip`.
