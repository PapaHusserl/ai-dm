# Правка сейва dusk_academy: пометка «все персонажи 18+»

Скрипт один раз правит в идущем мире `dusk_academy-d3de6c57` два поля слота `auto`: описание мира
(`world_text`) и заметки тона (`tone.notes`) — добавляет, что все персонажи совершеннолетние. Нужен Python 3
(других пакетов и репозитория не нужно). Подходят сейвы версии 9 и 10 (версию скрипт не меняет, игра обновит её при загрузке).

## Запуск

1. Закройте игру.
2. Скопируйте `migrate_dusk_18plus.py` в любую папку.
3. Выполните (путь — к папке мира внутри `saves`):
   - macOS / Linux: `python3 migrate_dusk_18plus.py ~/путь/к/saves/dusk_academy-d3de6c57`
   - Windows: `py migrate_dusk_18plus.py C:\путь\к\saves\dusk_academy-d3de6c57`
4. Скрипт напишет «Готово. Бэкап слота: …». Повторный запуск напишет «Уже применено» и ничего не изменит.
   При другой версии сейва или другом мире скрипт откажется и ничего не запишет.

Правится только слот `auto`; другие слоты (`auto-1`, `manual-*`) не меняются. Чтобы поправить другой слот,
передайте путь к его папке (`.../slots/auto-1`).

## Откат

Бэкап лежит в `saves/dusk_academy-d3de6c57/backup-18plus-<время>/auto`. Закройте игру, удалите
`saves/dusk_academy-d3de6c57/slots/auto` и скопируйте на его место папку `auto` из бэкапа.
