**Задача:** в TUI особые стрелы (варианты `attack:<лук>:<цель>:ammo:<стрела>`) не занимают по строке на вид стрелы,
а сворачиваются в одну строку-группу на лук («Стрелы ▸»), раскрываемую как «Заклинания на цель ▸»; плоский список,
движок, промпт и простой UI не меняются.

**Факт, который меняет картину (замер 2026-10-30, `measure111.py` на 140 вариантах t446, цель `guard_leader_1`):**
у героя t446 на цель 9 обычных атак (2 лука, кортик, гарпун, скимитар, клинок, безоружный, импровизированный,
бросок) + 12 строк стрел (2 лука × 6 видов) + 5 оглушающих. Сейчас на экране 8 атак + «Закончить ход» + «Ещё…»;
строки стрел **уже не на экране** — `fit` вытесняет их первыми среди rank 0 (они последние в плоском списке),
вместе с броском, «Идти», обезоруживанием и заклинанием (всё это в «Ещё…», 140 строк). Утверждение свинопаса
«стрелы забивают весь экран» по данным t446 не подтверждается. Значит, «Стрелы ▸» помогает только если строка группы
**переживает `fit`**: при группе после всех атак (rank 0) экран t446 не меняется вообще (замер: те же 8 оружий);
при группе сразу после строки своего лука — экран: лук, Стрелы ▸, кортик, гарпун, скимитар, короткий лук, Стрелы ▸,
клинок, Закончить ход (вытеснены безоружный, импровизированный, бросок). Это развилка Р1.

**Правило:** было — `target_block` (`combat_menu.py:151-168`): каждый вариант `kind == "attack"` цели →
`attack_row(...)` отдельной строкой; группируются только заклинания (`len(spells) <= SPELLS_INLINE` → строки, иначе
`MenuRow(SPELLS_TARGET_LABEL, kind="expand", group="spells_target", rank=3)`) → станет: атаки с `params["ammo"]`
выделяются из строк; на каждый лук (`params["weapon"]`) с числом видов стрел больше порога (Р2) — одна строка
`MenuRow(<подпись Р3>, kind="expand", group=f"ammo:{weapon}", rank=<Р1>)` на месте по Р1; `group_rows` для
`expanded.startswith("ammo:")` отдаёт «← Назад» + строки стрел этого лука (подписи — Р4). Всё остальное в
`build_view`/`fit`/`MenuState` — без изменений.
**Поведение:** меняется только в TUI (панель «Действия» в бою): вместо строк «Атака: <лук> — <стрела> (осталось N)»
— строка-группа; цифра/клик по ней раскрывает список стрел, Esc / «← Назад» — обратно (механизм `activate_row` →
`menu.expanded = row.group`, `action_menu_back` — `app.py:221-247`, без правок). «Ещё…» (F4) — по-прежнему полный
плоский список. Простой UI, `option_list` рассказчика, id и нумерация протокола — не меняются
(`test_list_options_ids_are_unchanged…`, `test_option_list_for_narrator_is_the_full_flat_list` остаются как есть).
**Вне ai-dm:** нет.
