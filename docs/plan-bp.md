## Суть

**Задача:** выстрел оружием с `ammunition` тратит боеприпас героя, без боеприпаса пункта выстрела нет, после победы
возвращается половина потраченного; стрелы — поштучно (данные, наборы, промпт, миграция живых сейвов).

**Что есть в коде (разведка 2026-10-30, a8d726f).** Обычный выстрел бесконечен: `arrows` — предмет «Стрелы (20 шт.)» за
100 мед. без механики (`srd/data/items/arrows.yaml`: ни `ammo_for`, ни `effects`); `attack()` (`combat/actions/attack.py:499`)
снимает со стека только особую стрелу (`ammo` из `params`); `docs/rules-adaptation.md:99` — «боеприпасы не считаются —
упрощение». Особые стрелы пака drunk_dragon (`arrow_fire` и др.: `ammo_for: [longbow, composite_longbow, …]`, `effects`)
уже расходуются поштучно (`combat/available.py:66` `special_ammo`, `:78` `ammo_options`, подпись «(осталось N)», группа
«Стрелы ▸» шага 111) и после боя не возвращаются (`tests/unit/combat/test_dragon_arrows.py`). Оружие с `ammunition`:
`shortbow`, `longbow`, `light_crossbow` (SRD) и `composite_longbow`, `composite_longbow_bound` (пак drunk_dragon); монстры
стреляют по статблоку без инвентаря. Живые герои (`saves/*/slots/*/heroes/*/hero.json`, чтение 2026-10-30): Томас
(u1_live), Арн (vale-43cd433c), Мира (dusk_academy-d3de6c57), Борг (vale-1e54eae8), Варн (test-273aadd1) — `shortbow`/`longbow`
+ `arrows` ×1 за 100 («20 шт.» в названии); Грей (drunk_dragon-00000001) — `composite_longbow_bound`, `arrows` ×9 за 100
(выдача рассказчика) и особые стрелы ×3…43. BACKLOG 215 («бандаж Вингтейла не подхватывает боеприпасы после боя», живой
прогон 2026-10-28) — Влад уже ждал подбора после боя.

**SRD 5.2.1, свойство Ammunition:** стрелять можно, только если есть боеприпас; каждая атака тратит один; после боя можно
вернуть половину потраченных, потратив минуту на поиск по полю; без боеприпаса оружие — импровизированное (не делаем:
импровизированное есть всегда). Цены: стрелы (20) 1 зм, болты (20) 1 зм, пули огнестрела (10) 3 зм, пули пращи (20) 4 мед.,
иглы (50) 1 зм.

**Правило** (первым пунктом аппрува): было `attack` (`attack.py:499`) `if ammo is not None: remove_item(engine.heroes[ref],
ammo)` и `attack_options` (`available.py:37-63`) — пункт на каждое оружие из `attacks_of` без проверки боеприпаса → станет:
- `attack_options`: пункт `attack:<оружие>:<цель>` у героя с оружием, у которого задан `weapon.ammo`, — только при
  `count_item(hero, weapon.ammo) > 0` (решение 4); подпись `f"Атака: {name} (осталось {n}) → {цель}"` (решение 5); особые
  стрелы (`ammo_options`) — как сейчас, независимо от обычных;
- `attack`: `ammo.spend(engine, ref, info, ammo)` — снимает особую стрелу (`ammo`) или один `weapon.ammo` и записывает
  потраченное во флаг героя `ActiveEffect(id="ammo_spent", kind="flag", source=ref, params={<item_id>: n})` (поля сейва
  нет — `ActiveEffect.params: dict[str, int | str | bool]`, `state/creature.py:31`); монстр — ничего;
- `settle_ground` (`combat/end.py:90`): после победы/завершения мастером (`won`, как у выбитого оружия) — `ammo.recover(engine)`
  возвращает половину (вниз) каждого вида, включая особые (решение 3), строка «<герой>: подобрал <название> ×N» (форма
  решения К2-17); бегство — ничего; флаг снимается всегда;
- `horde_options` (`available.py:384`): свободная атака луком без боеприпаса не предлагается (`ammo.can_shoot`).

**Поведение:** меняется — (1) меню боя: у лука/арбалета «(осталось N)» в подписи, пункт исчезает при 0 (простой UI и
`combat_options` рассказчика — та же подпись); (2) лог боя: после победы «Грей: подобрал стрелы ×3» (и особых — «подобрал
бронебойные стрелы ×2»); (3) `/inv`: «Боеприпасы: Стрелы x20 — 5 мед.» вместо «Стрелы (20 шт.) — 1 зм» в снаряжении;
(4) лавки: стрелы по 5 мед. за штуку, покупка `qty` до 20 за раз (`limits.give_item_max_qty = 20`, `config/defaults.toml:121`);
(5) создание героя: наборы следопыта/плута/воина-b и предыстория «Солдат» — «Стрелы ×20» (`kit_label`); лист героя у
рассказчика — 20 записей `arrows`; (6) живые сейвы при открытии мигрируют в v14 с бэкапом; (7) авто-герой без стрел бьёт
ближним (без правок — следует из (1)); (8) монстры — без изменений.
**Вне ai-dm:** нет.

**Схема сейва:** модели не меняются; миграция **данных** (решение 6) → `CURRENT_SCHEMA_VERSION = 14`, `m0014_v13_to_v14`,
отпечаток `tests/schema/save_v14.schema.json`, равный v13 по содержанию.
