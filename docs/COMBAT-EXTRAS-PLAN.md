# Партия «Боевые дополнения» (вне этапов, перед повторным живым прогоном этапа 5) — план

Папа-кабан, 2026-10-06, на утверждение. Решение пользователя 2026-10-06: безоружный удар, импровизированное оружие,
механика «Опутывающего удара». Код не меняется до аппрува.

**Задача:** три боевые механики SRD 5.2 в существующем движке без смены архитектуры и без миграции сейва.

## 1. Безоружный удар (закрывает BACKLOG 7, «трек 1.5»)
SRD 5.2: бросок атаки = мод. Силы + БМ (владение всегда); урон 1 + мод. Силы, дробящий (минимум 0 по SRD —
урон не ниже 0). Монахов в контенте нет (grep monk/unarmed пусто) — Боевые искусства не делаем, оставляем точку
расширения (см. вопрос В2). Варианты SRD «Захват/Толчок» в рамках удара — НЕ в этой партии (толчок/сбивание уже
есть в improvise).
- `combat/actions/attack.py::attacks_of` (ветка героя): в конец списка всегда добавлять
  `AttackInfo(id="unarmed", kind="melee", bonus=STR+PB, dice="0d0"/спец, damage_bonus=1+STR, damage_type="bludgeoning",
  weapon_id=None, name="безоружный удар", bonus_parts=[("Сила",..),("мастерство",..)], damage_parts=[("",1),("Сила",..)])`.
  Отдельная функция `unarmed_attack(hero)` в `rules/derived.py` (рядом с attack_bonus/attack_parts), чтобы карточка
  героя (`game/sheet_text.py`) могла показать строку «Безоружный удар».
- Урон без кости: проверить `roll_damage` с пустой костью — либо dice=None и ветка «фиксированный урон», либо
  поддержка в roll_damage. Крит: кость не удваивается, урон фиксирован (SRD: удваиваются только кости).
- `attack.py::perform`: `equip` только если `info.weapon_id is not None` (сейчас сравнивается `info.id` с main_hand —
  для "unarmed" вызовется equip несуществующего предмета). Мастерство (`mastery.on_hit/on_miss`) пропускать при
  weapon_id None — проверить, что они уже так делают.
- Боевые стили/эффекты к оружию (hero_effects): Дуэлянт и т.п. не применяются — damage_bonus считать без них.
- `available.py::attack_options` — изменений нет: оглушающая (nonlethal) уже даётся для любого melee героя,
  безоружный попадёт туда автоматически.
- Монстры не трогаем (у них свои действия).
- Состояние «disarmed» у героя (если появится) не мешает безоружному.

## 2. Импровизированное оружие
SRD 5.2: 1к4, тип урона по смыслу (по умолчанию дробящий), без БМ; бросок — дальнобойная 20/60; оружие, похожее на
настоящее, — как настоящее (это уже покрыто: предметы-оружие в инвентаре идут через attacks_of).
**Рекомендация (В1): фиксированный вариант меню, не через player_action/improvise.**
- improvise.py — это проверка навыка ради эффекта (prone/push/…), а не бросок атаки; смешивать нельзя.
  Импровизированное оружие — обычная атака: `AttackInfo(id="improvised", kind="melee", bonus=STR (без БМ),
  dice="1d4", damage_bonus=STR, "bludgeoning", name="импровизированное оружие")` и
  `AttackInfo(id="improvised_thrown", kind="ranged", bonus=STR, 1d4+STR, range 20/60)`.
- Источник предмета: НЕ инвентарь (у предметов нет признака «годится как дубина»; вводить поле в контент = миграция
  контент-моделей). Считаем, что подручное есть «в окружении» всегда (бутылка, табурет, камень); описание — дело
  рассказчика. Сделать опцию отключаемой флагом зоны/сцены не в этой партии.
- Брошенный предмет не исчезает и не учитывается (нет сущности) — осознанное упрощение.
- Порядок в меню: оружие → безоружный → импровизированное (ближ./бросок). Чтобы не раздувать меню (×цели ×nonlethal),
  оглушающий вариант для improvised оставить (SRD разрешает любую ближнюю), но см. риск R1.
- Связь с improvise.py: остаётся как есть; LLM-инструмент improvise не получает новых эффектов. В промпт рассказчика
  (game/turn.py / описание инструментов) — одна строка: «удар подручным предметом — это атака improvised, не improvise».

## 3. «Опутывающий удар» (ensnaring_strike)
Образец — «Метка охотника»: `spell_kind` по эффекту → `cast_options` → `cast.py` → ActiveEffect(expires=concentration)
→ хук в `attack.py::attack` после попадания (`mark_damage`).
- Контент `srd/data/spells/ensnaring_strike.yaml`: `effects: [{type: rider, condition: restrained, ability: str,
  dice: 1d6, damage_type: piercing, when: on_weapon_hit}]`. Новые значения: EffectType `rider` (или переиспользовать
  `condition`), EffectWhen `on_weapon_hit` — в `content/models/common.py` (литералы). Проверить, что остальные
  загрузчики/валидаторы контента не ломаются.
- `rules/spellcasting.py::spell_kind`: новый вид `"rider"` (проверка ДО mark). Цель — себя (`range_kind: self`):
  `cast.cast_targets` для rider → [ref]; метка `cast_options` «Опутывающий удар (заряд)».
- `cast.py::cast_rider`: тратит ячейку/бонус, ставит концентрацию (как cast_mark: старую сбросить через
  существующий путь), на героя `ActiveEffect(id="ensnaring_strike", kind="weapon_rider", source=ref,
  params={dice, damage_type, condition, ability:"str", dc: spell_save_dc, circle}, expires=concentration/owner=ref)`.
  Апкаст: dice = (circle)d6. Регистрация в таблице `cast.py` (строка 315).
- `attack.py::attack`: после `special_damage`, только при `info.weapon_id is not None` или improvised? — по SRD «попадание
  оружием»: безоружный — НЕ оружие, improvised — оружие (решение в В3). Функция `weapon_rider(engine, ref, target, …)`:
  снимает заряд с героя; размер цели ≤ large (Monster.size; герои — species.size); спасбросок Силы цели против dc
  (существующий механизм спасбросков монстров — найти в area.py/cast.py, area-заклинания уже бросают спас).
  Провал → `AppliedCondition(id="restrained", source=ref, expires=Expiry(kind="concentration", owner=ref))` +
  `ActiveEffect(id="ensnared", kind="ensnared", source=ref, params={dice, damage_type, dc}, expires=concentration)`.
  Успех → заряд всё равно израсходован, концентрация кончается (SRD: заклинание завершается) — `drop_concentration`.
- Концентрация: `engine.drop_concentration_effects` сейчас снимает только active_effects — ДОПОЛНИТЬ снятием
  conditions с expires.kind == "concentration" (иначе restrained останется навсегда). Также проверить
  `rules/creatures.py::end_concentration` и `spellcasting.drop_concentration` (вне боя) — тот же фильтр.
- Урон в начале хода: `engine.burn` обобщить на kind "ensnared" (или отдельный `ensnare_tick` рядом, вызываемый в
  start_turn) — 1к6×circle колющий, источник = заклинатель (для downed/кредита убийства).
- Вырваться: `available.py` — новая опция `escape:<spell>` kind "escape", cost action, для участника с эффектом
  ensnared; perform в `combat/actions/standard.py`: проверка Силы (Атлетика) против dc (`rules/checks.skill_check`
  для героев; для монстров — бросок Сила-мод, как в существующих проверках монстров). Успех → снять restrained+
  ensnared с себя (концентрация заклинателя остаётся? SRD 5.2: при успехе цель освобождается и заклинание
  заканчивается — снять через drop_concentration заклинателя). Контроллер ИИ монстра (`combat/controllers.py`): дать
  ему выбирать escape, если он restrained и альтернатива — атака с помехой (простая эвристика: escape, если restrained).
- Вне боя заряд: rider кастуется только в бою (cast_options боевой); вне боя — через spells-меню не предлагать
  (spell_kind rider пропускать в мирном касте) — проверить protocol/handlers/resources.py.
- Карточка/лог: restrained уже имеет подпись «опутан» (rules/modifiers/conditions.py) и модификаторы (помеха атакам,
  преимущество атакующим, скорость 0) — переиспользуются.

## Миграции сейва
Не нужны: ActiveEffect.params/kind — свободные str; AppliedCondition уже имеет expires; Expiry "concentration" есть.
CURRENT_SCHEMA_VERSION=5 не меняется. Живые сейвы в saves/ не трогать. Тест: загрузка фикстуры сейва v5 с героем
без заряда — без ошибок.

## Тесты (TDD, писать первыми)
Безоружный:
- герой с мечом → в attacks_of есть "unarmed" последним; герой без оружия → только "unarmed" (раньше пусто).
- бонус = STR+PB; урон 1+STR, дробящий; крит → урон не удвоен; STR -1 → урон 0 (не отрицательный).
- perform unarmed не вызывает equip, main_hand не меняется; мастерство не срабатывает.
- оглушающая безоружная атака доводит до 0 → nonlethal (без смертельных спасбросков).
- стиль «Дуэлянт» не прибавляется.
Импровизированное:
- опции improvised (melee) и improvised_thrown (ranged 20/60) есть у героя; бонус без БМ.
- бросок дальше 60 фт недоступен; 21–60 — помеха; в ближней зоне ranged — помеха как у прочих.
- урон 1d4+STR дробящий; improvise() (навык) работает как раньше (регрессия).
Опутывающий удар:
- spell_kind(ensnaring_strike)=="rider"; hunters_mark по-прежнему "mark".
- cast_options: бонусное действие, цель — сам; трата ячейки; концентрация установлена; старая концентрация снята.
- попадание оружием при заряде → спас Силы; провал → restrained+ensnared, заряд снят; успех → заряд снят, концентрация кончилась.
- промах → заряд остаётся.
- безоружный удар не тратит заряд (если В3 по рекомендации).
- цель Huge+ → спаса нет, заряд тратится (SRD: эффекта нет) — уточнить в В4.
- начало хода опутанного: 1d6 колющего (апкаст 2 ур. → 2d6), источник — заклинатель.
- escape: успех → состояния сняты, концентрация заклинателя окончена; провал → действие потрачено, всё на месте.
- потеря концентрации (урон заклинателю, провал спаса конц.) → restrained и ensnared сняты (новый фильтр conditions).
- конец боя → эффекты с концентрацией сняты (регрессия текущего поведения).
- монстр-ИИ в restrained выбирает escape.
- загрузка сейва v5 без изменений.
Мутационное тестирование — по правилам HANDOFF (без недостижимых фолбэков, ср. коммит 4f4783c).
