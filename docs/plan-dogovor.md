## Суть

Мира и Люциан встречаются; по Договору Хранителей связь ночного народа с человеком отравляет Люциана и
остров; расставание возвращает равновесие, новое сближение — запускает всё заново. Механики недуга в движке нет
(решение 0): отравление и откат ведёт рассказчик. Врезка входит через гадалку; живой мир `dusk_academy-d3de6c57`
лежит у игрока на другом компьютере, доставка — `git pull` + одноразовый скрипт (решение 7).

**Правило:** новое — в движке правил не меняется; в данных: флаг `pact:together` (ставит скрипт и рассказчик) →
триггеры фракции пака `if: {flag: pact:together}` / `value: false`. Код движка не трогается (при Р4 = а).
**Поведение движка:** не меняется. **Вне репо:** игрок с сейвом — `git pull`, запуск игры (догрузка пака v4),
выход, скрипт по инструкции `docs/migrate-dusk-pact.md`; передаёт Влад.

## Риски

- Пара у игрока на t1080 — в паузе («дружеская дистанция»): скрипт ставит `pact:together = true` по решению Влада
  «они встречаются»; если Влад считает паузу расставанием — `false`, и беды не начнутся, пока рассказчик не поставит
  `true` (вопрос 1).
- Рассказчик не ставит флаг → при Р3 = а беды не кончаются; видно по «За кадром» после расставания — лечится
  `narrative`-веткой без скрипта (новая версия пака не поможет существующим триггерам; потребуется второй скрипт или
  правка `world.json` руками). Поэтому фразу про флаг — и в `notes` Люциана, и в `world_text`.
- Порядок у игрока «сначала игра, потом скрипт» — скрипт отказывает с подсказкой; если он сыграл сцены между
  загрузкой и скриптом — ничего не ломается (`blight_sign` без флага молчит, `fortune_visit`/`calm_sign` спят).
- `world_text` — кэш-блок рассказчика; дописанный абзац увеличит его на 300–500 знаков, под бюджет STATIC_MAX не
  попадает (это `world_block`, не статическая оценка? — проверить в П2 шага: `master/prompt.py:static_estimate`
  учитывает `world_text`; при превышении порога — сократить абзац).
