### 2. Техдолг по баг-репортам → партии

#### Т60 «Сеть» — мини ≈ 0,5, сейв v9, без полей

- `GeminiAdapter.get_client`: `client_args={"transport": httpx.HTTPTransport(local_address="0.0.0.0")}` при

  `profiles.anthropic` и ручной `/model` не трогаем.

  лог старта попытки в журнале (висящая попытка сейчас не пишется).
