# Шаг 209 — тесты окна выбора модели в TUI падают на HEAD (BACKLOG 209)

## Суть
Три теста окна `/model` (test_tui_live1.py, test_tui_live1_edges.py) падают на HEAD. Причина — по груминг-отчёту
свинопаса: коммит 809b059 убрал Claude из меню `/model`, а тесты TUI стартуют с моделью anthropic:claude-opus-5-5;
пользовательский config.toml ни при чём (HOME подменяет фикстура tests/unit/conftest.py).

## Решения (Влад, 2026-10-27)
1. Окно `/model` не показывает текущую модель, если её нет в конфиге: меню как есть, правим только 3 теста (В1).
2. Ссылка в BACKLOG 209 — на Н5 отклика Декарта, не Н4 (В2).
3. Тесты чиним, без skip/xfail (В3).
4. Шаг — полным конвейером: папа → тесть → аппрув → кабан → доеба → мама ‖ свекровь (В4).
5. Р1(б): текущая модель в тестах — из `settings().app.roles.narrator`, не литералом (аппрув плана).
6. Р2(а): добавить тест «текущей модели нет в конфиге → в окне нет «(текущая)»» (аппрув плана).
7. Умолчания плана приняты: параметры `provider`/`model` в `text_app`/`build_app`, по умолчанию OPUS.

## План (папа-кабан, 2026-10-27)

**Правило:** нет. Продуктовый код не меняется: `model_options` (src/ai_dm/game/models.py:7) и подсветка
`if self.current in self.options` (src/ai_dm/ui/tui/modals.py:84) остаются (решение 1).
**Поведение:** не меняется.
**Вне репо:** нет. Отдельно: в docs/ROADMAP.md («Вставки без перебора», строка 209) ссылка «отклик Декарта Н4» →
Н5 (решение 2) — правит архитектор после аппрува, в коммите шага; в BACKLOG 209 — так же Н4 → Н5.

**Причина (проверено grep):** тесты строят игру через `text_app` (tests/unit/ui/ui_kit.py:138) с адаптером
`anthropic:claude-opus-5-5` и `model=OPUS` (`build_app`, ui_kit.py:123). После 809b059 этого ключа нет в меню:
roles.narrator = gemini:gemini-3.8-flash, alternatives.narrator = openai:gpt-6.1-sol, narrator_chain начинается
с gemini-3.8-flash (src/ai_dm/config/app_defaults.toml:2–4, 23–26, 202). Цена gemini-3.8-flash есть (там же, :56).

**Файлы/функции:**
- tests/unit/ui/ui_kit.py — `build_app`, `text_app`: добавить именованные `provider="anthropic"`, `model=OPUS`
  (по умолчанию как сейчас — остальные тесты не меняются), пробросить в `ScriptedAdapter` и `make_app(model=…)`.
- tests/unit/ui/tui/test_tui_live1.py — `model_app` (:184): `text_app(..., provider="gemini",
  model="gemini-3.8-flash")`; тела `enter_picks_highlighted_current_model` (:239), `down_enter_picks_next_model` (:256)
  не меняются.
- tests/unit/ui/tui/test_tui_live1_edges.py — `test_model_window_marks_only_current_and_has_title` (:205): тот же
  ключ в `text_app`. Если `last_digit_picks_last_model` (:220) переводить единообразно — по желанию, он зелёный.
- src — 0 файлов; mutmut не нужен (AGENTS.md: только по изменённым функциям src).

**Партии:** одна.
1. ui_kit + 2 файла тестов (выше). Проверка: `uv run pytest -q tests/unit/ui/tui/test_tui_live1.py
   tests/unit/ui/tui/test_tui_live1_edges.py -p no:randomly -k model_window` → 0 failed; затем весь
   `tests/unit/ui/tui`; в конце партии `make cov`, `make smells` (не выше), `make dead`, ruff.

**Тестовые сценарии:**
- текущая gemini:gemini-3.8-flash → меню `[openai:gpt-6.1-sol, gemini:gemini-3.8-flash, gemini:gemini-4-argon, …]`
  (следующая по цепочке первой, models.py:20–23), подсвечен пункт 2 «(текущая)» ровно один; Enter → set_narrator
  gemini:gemini-3.8-flash; down+Enter → gemini:gemini-4-argon. Ожидание, не проверено (вывод из кода, прогона нет).
- остальные 8 тестов `-k model_window` и тесты /model в test_tui_entry_points.py остаются зелёными (там OPUS
  не в меню, но они не ищут текущую). Ожидание, не проверено.

**Развилки и риски:**
- Р1. Откуда тест берёт ключ текущей модели. (а) литерал "gemini"/"gemini-3.8-flash" в model_app — просто,
  но сломается при следующей смене дефолтов, как 809b059; (б) из `settings().app.roles.narrator` — не ломается
  при смене дефолта. Рекомендую (б). Решает Влад.
- Р2. Закрепить тестом решение 1: новая проверка «текущей (OPUS) нет в конфиге → в окне нет «(текущая)», ничего не
  подсвечено по ней». (а) добавить один тест в test_tui_live1_edges.py — решение 1 становится проверяемым;
  (б) не добавлять — минимум под пункт. Рекомендую (а): без него решение 1 держится только на коде. Решает Влад.
- Риск: флаки `digit_key` (207) в шаг не входит; упадёт в `make cov` — отдельный пункт BACKLOG с именем и seed.
- Риск расползания: не переводить все тесты TUI с OPUS на gemini — только 3 падающих (+ Р2).

**Умолчания (внутреннее):** имена параметров `provider`/`model` в `text_app`/`build_app`; значения по умолчанию
сохраняют OPUS.

**Открытые вопросы:** Р1, Р2 — к Владу при аппруве; блокирующих нет.
