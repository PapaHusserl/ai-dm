### Разведка механизмов

1. Провайдер-зависимых частей промпта сейчас нет. Провайдер в сборке виден в двух местах: `PromptBuilder.build`
   (prompt.py:246, `cpt_for(self.role_cfg.provider)`) и `api_tokens(usage, provider)` (session.py:34, ветка
   `provider == "gemini"`). Правила — один блок `SystemBlock(text=self.rules, cache=True)` (prompt.py:268); текст правил
   обещает «Данные мира лежат в system[1]» (narrator_rules.md:42), на индексы system завязаны тесты в 10 файлах
   (`len(req.system)`, `system[1]`) — добавку класть **внутрь блока правил**, а не отдельным блоком.
   Кэш: OpenAI — implicit-кэш префикса, `instructions` = склейка system-блоков (openai_adapter.py:124); добавка в хвосте
   правил — одноразовая перезапись статики (~250 токенов × $2,5/M), дальше читается по $0,10/M. Anthropic/Gemini —
   добавки нет, их кэш меняет только ориентир длины (одноразово, неизбежно при решении 2).
   Бюджет: `static_tokens("explore")` сейчас 21253 (rules 10476, tools 10777) при `STATIC_MAX` 21620 — запас 367 токенов
   ≈ 900 знаков при cpt 2,5. Ориентир длины (~150–200 знаков ≈ 60–80 токенов) влезает. Добавка OpenAI (~500–700 знаков
   ≈ 200–280 токенов) влезла бы впритык, но `static_tokens` по контракту не зависит от провайдера
   (`test_static_tokens_do_not_depend_on_role_provider`, `test_rules_tokens_are_estimate_of_rules_file_by_common_cpt`) —
   добавку в общий замер не включать, а ограничить отдельным потолком (см. умолчания).
2. О длине в правилах: narrator_rules.md:156 «Пиши развёрнуто… Обычно 3–6 абзацев» и :162 «Если ответ оборвался из-за
   длины, в следующий раз пиши короче». Чисел нет; GPT укладывается в «3–6 абзацев» короткими абзацами.
   Рычаг только для OpenAI: параметр Responses API `text.verbosity` (low/medium/high, умолчание medium; адаптер его не
   передаёт) — развилка Р3, не замена ориентиру в правилах.
3. Повтор `ask_choices` для OpenAI как страховка: цена ≈ короткий вызов — чтение 26,5k × $0,10/M = $0,0027 + запись
   ~500 × $2,5/M = $0,0013 + вывод 100–300 (с мышлением) × $10/M = $0,001–0,003 → **≈ $0,005–0,007 за повтор** (+15–20 % к
   ходу $0,03). Страховка на каждом explore-ходе без `offer_choices` в этой игре сработала бы 10/10 → ≈ +$0,06 на 10 ходов.
   Нужна ли — зависит от того, достаточно ли добавки правил; проверить можно только живой игрой → развилка Р1.
