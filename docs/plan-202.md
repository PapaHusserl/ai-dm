# Шаг 202 — ускорить тесты и разбор мутантов без потери качества

BACKLOG 202. Запрос проектировщика 2026-10-25: «оптимизировать наши тесты и ревью мутантов по времени, не теряя
качества». Ресёрч — docs/research/test-speed-research.md (кабан-кволити, 2026-10-25).

## Суть

Сократить время полного `make cov` и разбора мутантов; качество проверок не снижать (критерий — решение 5).

## Решения

Груминг 2026-10-25 (свинопас, аудит свекрови), окна проектировщику:

1. pytest-xdist — ставим (dev-зависимость); первый прогон сверяет число passed с базой.
2. Маркер `slow` (Textual-Pilot) — всегда входит в `make cov`; отключается только на итерациях.
3. `# pragma: no mutate` для текстов сообщений — первый список утверждает проектировщик, затем правило в AGENTS.md
   (ставит доеба, проверяет мама).
4. pytest-testmon — потом: после замера xdist и mutmut; если итерации долгие — отдельный пункт беклога.
5. Критерий «без потери качества»: после шага `make cov` проходит то же число тестов, покрытие ≥ 94 %, smells ≤ 200,
   mutmut находит тех же выживших на контрольной функции. Цель — `make cov` ≤ 20 мин (база 49 мин, ДН П1).
6. `mutate_only_covered_lines` — не включаем (новая строка без теста должна оставаться видна в мутантах).
7. AGENTS.md («≈ 45 мин без xdist», `make mutate`, правило pragma) правит оркестратор в коммите той партии, что меняет
   поведение; цифры — из замера.
8. Развилки плана Р1–Р7 — по рекомендациям папы (2026-10-25): `-n 6 --dist loadfile`; `--max-children` 4; diff от
   HEAD; контрольная функция `PromptBuilder.state_data`; `slow` хуком на каталог tui; ставить pytest-xdist 3.8.0;
   партии 0–4 раздельно; `--durations=30` в каждом `make cov`.
9. Мутант, которого `mutate-diff` не привязал к строке (нет функции, исходника или `mutmut show`), — в отдельный
   список «не распознано»; не в «старые» (2026-10-25, по аудиту свекрови П1).
10. Переменную `BASE` и флаг `--base` убрать — diff только от HEAD, как в Р3 (а) (2026-10-25, по аудиту свекрови П1).
11. Неотслеживаемые файлы `src` скрипт считает новыми целиком (`git ls-files --others --exclude-standard -- src`), с
    тестом (2026-10-25, по ревью мамы П1, рекомендация мамы).

## План (папа-кабан, 2026-10-25)

**Правило:** было `cov: uv run pytest -q --cov --cov-report=term` (Makefile:25–26) → станет
`uv run pytest -q -n $(XDIST) --dist loadfile --cov --cov-report=term --durations=30` (значения `XDIST`, `--dist` — Р1).
Мутанты: было «разбор всех выживших функции из FUNCS» → станет «разбор выживших, чья строка в `git diff -U0`»
(остальные — списком в BACKLOG, как правило 4 «Экономии конвейера»).
**Поведение:** игры — не меняется; меняется вывод `make cov` (топ-30 долгих тестов), цели Makefile, правила AGENTS.md.
**Вне ai-dm:** нет.

**Находки разведки (проверено):**
- `MUT_ARGS` в Makefile:15 — это шаблоны мутантов из FUNCS/MOD. `make mutate MUT_ARGS="--max-children 6"` (так предлагает
  груминг, раунд 2) **затирает шаблоны** — mutmut пойдёт по всем модулям. Нужна отдельная переменная (новая, `MUT_CHILDREN`).
- `mutmut show` даёт diff функции с номерами строк **внутри функции** (mutmut/mutation/diff_apply.py:151–158), не файла.
  Фильтр по `git diff -U0` должен сам найти начало функции в исходнике (ast по имени из ключа мутанта) и сдвинуть.
- `mutmut results` без `--all` печатает только не-killed (`__main__.py:1102–1111`) — вход фильтра.
- Pilot/run_test: 24 файла — 18 в tests/unit/ui/tui (20 файлов в каталоге), 2 в tests/unit/ui, 1 game, 3 scenarios;
  `def test` в них — 562 (grep). Тесты синхронные (`asyncio.run`, async def test — 0).
- Дублей имён тест-файлов нет (`basename | uniq -d` — пусто): конфликт `pythonpath` при xdist маловероятен, но
  tui/conftest.py делает `sys.path.insert` — проверяется пробным прогоном.
- Тесты, трогающие общий дом: `Path.home()/expanduser` — tests/unit/ui/test_ui_cli.py, tests/unit/devtools/test_check_install.py
  — первые кандидаты на флак под xdist.
- conftest: `app_defaults_zero_min` — session + `tmp_path_factory` (на воркер свой каталог, под xdist безопасно);
  `durable_off` — autouse function.
- pytest-xdist на PyPI: 3.8.0 от 2025-07-01 (проверено curl PyPI); проект живой (pytest-dev), но релиз ~16 мес. назад — Р6.
- pragma в mutmut 3.8: `# pragma: no mutate` и блочная форма (`mutation/pragma_handling.py`).
- Ядер 8 (`sysctl hw.ncpu`).

**Развилки (решает проектировщик):**
- Р1. xdist: (а) `-n 6 --dist loadfile` — рекомендую: оставляет 2 ядра машине, файл целиком в одном воркере (фикстуры
  module не дублируются); (б) `-n auto` — все 8, быстрее на свободной машине, душит соседей (mutmut, игра).
- Р2. `--max-children` по умолчанию: (а) 4 — рекомендую при параллельном cov; (б) 6; (в) не задавать (= 8, как сейчас).
  Риск segfault (Makefile:44) от числа процессов — не проверено, смотреть в партии 1.
- Р3. База диффа для отсева: (а) `git diff -U0 HEAD` (незакоммиченное, как сейчас MOD) — рекомендую, mutmut гоняется
  до коммита партии; (б) `git diff -U0 <коммит до партии>` — переменная BASE, для партий из нескольких коммитов.
- Р4. Контрольная функция: (а) `ai_dm.master.prompt:PromptBuilder.state_data` (prompt.py:529; 62 выживших по ресёрчу) —
  рекомендую, много шума, показательно для 1 и 4; (б) маленькая чистая функция (rules.money) — быстрее, но мало сигнала.
- Р5. Как ставить `slow`: (а) хук `pytest_collection_modifyitems` в tests/unit/ui/tui/conftest.py — весь каталог tui —
  рекомендую: одна точка, новые tui-тесты попадут сами; (б) `pytestmark = pytest.mark.slow` в каждом из 24 файлов —
  точнее (ловит 6 вне tui), но новые файлы забудут.
- Р6. pytest-xdist 3.8.0 — релиз 2025-07; альтернатив в экосистеме нет (pytest-parallel заброшен). Рекомендую ставить.
- Р7. Партии: (а) 4 партии как выше — рекомендую (каждая со своим замером); (б) слить 1+3 (обе без зависимостей).
- Вывод `--durations=30` в каждом `make cov` (+30 строк) — видимо; альтернатива — отдельная цель `make durations`.
  Рекомендую в cov: топ нужен кабану-тестю каждый раз.

**Риски:** флаки под xdist (общие файлы дома, порядок) — партия 2 чинит; xdist+mutmut: mutmut свои прогоны делает
без `-n` (cov-цель его не трогает) — ожидание, не проверено; разные строки при `pytest-cov` под xdist — сверка %.
