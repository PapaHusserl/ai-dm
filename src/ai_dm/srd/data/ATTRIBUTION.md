## Монстры (К7д)

- `monsters/` — числа (КД, HP, характеристики, ПО, скорости, бонусы атак и кости урона) получены одноразовым импортом
  из Open5e API v2, документ `srd-2024` («System Reference Document 5.2», CC BY 4.0), 2026-10-14.
- Иммунитеты, сопротивления и уязвимости сверены с официальным PDF SRD 5.2.1 и взяты из него: в данных Open5e для
  7 монстров (скелет, тень, призрак, пылевой мефит, огненный и земляной элементали, рой крыс) часть этих полей пуста.
- Русские названия, описания черт и действий — перевод проекта. Скрипт импорта в репозиторий не входит.
