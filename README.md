# AI-DM

Движок правил D&D 5.5e (на основе SRD 5.2) с ИИ-мастером. Этап 1 — движок правил без ИИ. Этап 2 — ИИ-мастер
(Claude / Gemini), протокол запросов, атомарный ход, журнал вызовов, учёт стоимости и простой построчный интерфейс.

## Установка

```
uv sync
uv run pytest -q
uv run ruff check src tests devtools
```

Звук (необязательно): `uv sync --extra audio` или `pip install "ai-dm[audio]"`.

## Как играть

Ключи. Нужен ключ рассказчика: `GEMINI_API_KEY` (Gemini, по умолчанию), `ANTHROPIC_API_KEY` (Claude Opus) или `OPENAI_API_KEY` (OpenAI, gpt-6.1-sol).
Если нет ключа Gemini, игра сама возьмёт первый профиль, для которого есть ключ (anthropic, затем openai), и скажет об этом; мир,
сохранённый под Anthropic или OpenAI, открывается без ключа Gemini. Явный выбор для нового мира: `--provider anthropic|gemini|openai`;
в игре — `/model narrator openai:gpt-6.1-sol`. Ключ берётся из переменной окружения или из файла `.env` в папке, откуда запускаете игру
(`.env` лежит в `.gitignore`, не коммитьте его):

```
ANTHROPIC_API_KEY=...
GEMINI_API_KEY=...
OPENAI_API_KEY=...
```

Ключи нигде не печатаются и не попадают в журнал.

Новый мир (пак кампании из `campaigns/<id>`, по умолчанию `vale`; герой — пресет пака: в Вейле Арн, Лиэль или Грей;
без `--hero` игра спросит):

```
uv run ai-dm --new [--campaign vale] [--hero arn|liel|grey | --hero-describe "описание"] [--preset heroic|grim|romantic|fairytale] [--seed N] [--provider anthropic|gemini|openai]
```

Сущности пака, конфликтующие по id или имени, не загружаются — список печатается при старте. При загрузке мира новые
сущности пака добавляются в мир (существующие не меняются).

Мир получает id вида `vale-1a2b3c4d` (он же имя папки в `saves/`). При старте игра печатает строку
`Мир: <id>, сид <N> (продолжить: ai-dm --world <id>)`; забыли id — посмотрите имена папок в `saves/`. Продолжить мир с последнего автосохранения:

```
uv run ai-dm --world <id>
```

Другая папка сейвов: `--saves DIR` (по умолчанию `./saves`).

Режимы. В настоящем терминале игра по умолчанию открывается в TUI (Textual): лента рассказа, справа лист героя, «Броски»,
«Бой» и «Получено», внизу строка состояния и поле ввода. `--simple` включает простой построчный режим без TUI. В простой режим игра
уходит сама: если ввод или вывод не терминал (pipe, файл, тесты), `TERM=dumb`, не установлен textual или TUI не смог стартовать
(печатается «TUI не запустился: …, простой режим»).

```
uv run ai-dm --new --hero arn --simple
```

Клавиши TUI: цифра выбирает вариант или пункт меню (пока поле ввода пусто), клик по варианту тоже; F2 показывает/скрывает панель
героя (в узком терминале, меньше 120 колонок, она открывается поверх ленты); Esc закрывает окно ответа команды;
Ctrl+C (или Ctrl+Q) вне хода выходит с автосохранением; во время хода мастера первое нажатие ждёт конца хода и выходит с
автосохранением, второе выходит сразу без сохранения (код 130). Ctrl+C при подготовке мира печатает строки старта и «Прервано.» (код 130). `/sheet`, `/inv`, `/spells`, `/abilities`, `/model`, `/cost`, `/lore`
в TUI отвечают окном (`/cost` таблицей период, роль, модель, сумма; `/lore` — справочником: сущности слева, записи справа); остальные команды и их смысл те же, что в простом режиме.

В игре вводите текст действия, как в разговоре с мастером. Если мастер предложил варианты, можно ввести номер. В бою
показан список действий: номер выполняет действие без вызова модели на разбор (рассказ после хода — вызов модели), текст разбирает мастер. Если ход упал (ошибка
сети, отказ модели), игра предложит меню: повторить, сменить модель, сохранить и выйти. Под каждым ответом строка
состояния: `HP · дата и время · сессия $`.

Команды (`/help` показывает список):

| Команда | Что делает |
|---|---|
| `/help` | список команд |
| `/save [имя]` | сохранить в слот `manual-<имя>` (без имени `manual-quick`) |
| `/load [имя]` | загрузить слот `manual-<имя>` (без имени последнее автосохранение) |
| `/model` | показать модели; `/model narrator <провайдер:модель>` сменить модель рассказчика (запоминается в мире) |
| `/cost` | расходы на модель: сессия, день (все миры, местное время), мир, по ролям и моделям |
| `/sheet`, `/inv` | лист героя, инвентарь |
| `/lore [имя]` | журнал знаний героя: кто, что, откуда; с именем — записи об одной сущности |
| `/quit` | сохранить (auto) и выйти; EOF (Ctrl-D) тоже сохраняет |
| `/report <что не так>` | записать репорт об ошибке в `saves/<мир>/issues/` (каталог с `report.md` и `meta.json`); репорт пишется и сам, если ход получил метку (`missing-mechanic`, `limit-exceeded`, `invalid-death`, `refusal`, `invalid-defeat`, `context_overflow`); в `--mock` и `--replay` авто-репорты не пишутся |
| `/fight <монстр xN, …>` | отладка: бой с заданным составом, например `/fight goblin_warrior x3` |
| `/tone`, `/retire` | заглушки (этапы 3, 9) |

## Для разработки: без сети и ключей

```
uv run ai-dm --new --hero arn --seed 3 --mock tests/fixtures/scripts/talk_check_fight.yaml
uv run ai-dm --replay --world <id> --hero arn --seed 3
```

- `--mock PATH` — вместо модели ответы из YAML-сценария. Ключ не нужен, сохранённая модель мира не подключается.
  Ограничение: сценарий `talk_check_fight.yaml` кончается на начале боя, бой руками с моком не доиграть (бой проверяется живой моделью).
- `--preset ID` — пресет мира для нового мира (`heroic`, `grim`, `romantic`, `fairytale`): оси тона и голос рассказчика
  накладываются на тон пака, ограничения пака сохраняются. Без флага — тон пака (или `preset` из его `campaign.yaml`).
- `--hero-describe TEXT` — герой на лету: ИИ собирает лист героя по вашему описанию (только с `--new`, несовместимо с `--hero` и
  `--replay`); без текста герой создаётся в диалоге: пункт «Создать героя на лету» в выборе героя (у пака без пресетов героев — сразу).
  Пункт «Создать пошагово» собирает героя по шагам без ИИ: вид, класс, предыстория (из четырёх или «Описать словами» — один вызов ИИ),
  характеристики (стандартный набор, покупка очков или свободный ввод), навыки, заклинания, набор, имя, мотив и средства. Номер пункта — выбор,
  «назад» — шаг назад, «отмена» — выйти; в конце лист можно принять, вернуться к шагам (откатывается последний шаг) или поправить поля.
  В TUI над меню выбора героя и на экране создания показывается заставка.
  Лист записывается в `saves/<id>/meta/hero_sheet.json`; расход создания печатается строкой «Создание героя: $…».
  При интерактивном старте (без `--hero`, `--hero-describe`, `--preset`) после героя спрашивается пресет мира («Как в паке» или один из четырёх).
- `--replay` — ответы из журнала `saves/<id>/journal` (обязательны `--world`, `--seed` и `--hero` исходного прогона — или лист героя на лету в `meta/hero_sheet.json` мира — и `--preset`, если он был;
  `--new` подразумевается). Стартует новый мир с тем же сидом, ходы вводятся те же (запрос не совпал с журналом —
  `ReplayDivergence`). Ключ не нужен. Игра идёт во временной папке (путь выводится при запуске), живой мир не меняется.
- `--replay-report PATH` — воспроизвести ход из каталога репорта (`saves/<мир>/issues/<имя>`): ход заново по снимку `before/` и записям
  `journal/calls.jsonl`, без сети и ключей. Несовместим с `--new`, `--world`, `--replay`, `--mock*`. Выводит рассказ хода и
  «Состояние совпало.» (код 0), либо список расхождений или расхождение с журналом (код 1). Репорт без журнала, без хода или
  нечитаемый — код 2. Живой `saves/` не трогается (всё во временной папке).

## Импорт пака из выжимки

```
uv run ai-dm --import выжимка.txt --campaign my_pack [--provider anthropic|gemini|openai]
```

ИИ собирает пак кампании из текстовой выжимки (заметки, описание мира, итоги сессии) одним вызовом и пишет его в
`campaigns/<id>/`: `campaign.yaml`, `world.md`, `truths.md`, `locations.yaml`, `npcs.yaml`, `factions.yaml`, `pantheon.yaml`
(пустые списки и `truths.md` не пишутся). На диск попадает только пак, который грузится без ошибок и без конфликтов имён:
ошибки загрузчика («файл: поле: что не так») уходят модели, до трёх попыток; после — меню «повторить / сменить модель / выйти».
Героев, событий (`events.yaml`) и стартовой памяти (`start/`) импорт не создаёт: герой создаётся при старте мира
(«на лету» или пошагово). После импорта правьте файлы руками, потом `ai-dm --new --campaign my_pack`.

- Нужен `--campaign <id>`; если `campaigns/<id>` уже есть — отказ (код 1), файлы не меняются. Несовместим с `--new`, `--world`,
  `--hero`, `--hero-describe`, `--preset`, `--seed`, `--replay`, `--replay-report`, `--mock-world`, `--mock-summarizer` (код 2).
- `--mock PATH` — сценарий вместо модели. Выжимка длиннее `[import] max_chars` (по умолчанию 60000 символов) отклоняется до вызова.
- Модель — роль `import` (`[roles.import]`, `[profiles.*.import]`). Расход печатается строкой «Импорт пака: $…».
- Журнал вызовов импорта лежит в `campaigns/<id>/.import/journal/` (выжимка и ответы модели; в git не попадает).

## Где что лежит

```
saves/<id>/slots/              слоты сохранений (auto с ротацией, manual-*)
saves/<id>/journal/            журнал вызовов модели (calls-NNN.jsonl, blobs/), без ключей
saves/<id>/meta/costs.jsonl    учёт стоимости (откат и загрузка деньги не возвращают)
saves/<id>/meta/models.json    выбранная модель рассказчика
```

Автосохранение пишется на границе сцены. Мягкий лимит трат (секция `[cost_limits]` в `src/ai_dm/config/app_defaults.toml`, по умолчанию выключен):
предупреждение на `warn_percent`, на лимите (сессии или дня, что раньше) игра спрашивает «продолжить» или «сохранить и выйти». «Продолжить» отключает паузы
до конца сессии.

## Музыка и эмбиент

Тематическая музыка и фоновые звуки (толпа в таверне, ветер, капель) — только в TUI, по ситуации: бой > локация (id, теги,
теги родителей) > тон мира. Простой режим, создание героя, пикер, `--replay`, `--import` и `--mock` — без звука. Звук необязателен:
нужен extra `audio` (`uv sync --extra audio` / `pip install "ai-dm[audio]"`; без него TUI пишет
одну строку «Звук выключен: …» и молчит). Нет библиотеки или звукового устройства (SSH) — то же, игра идёт как обычно.

- `/music` — состояние; `/music on|off`; `/music 0–100` — громкость; `/music ambient on|off` — эмбиент. В простом режиме команда
  отвечает «Звук выключен: звук только в TUI».
- `--mute` — без музыки в этом запуске (в настройки не пишется).
- Настройки: `~/.config/ai-dm/` (`$XDG_CONFIG_HOME/ai-dm`, или `$AI_DM_CONFIG_DIR`). `config.toml` правите вы (любые секции из
  `app_defaults.toml`, в том числе `[audio]` с дефолтами; секции правил — `[limits]`, `[disarm]`, `[time]` и прочие из
  `defaults.toml` — `config.toml` не принимает, они правятся только в `src/ai_dm/config/defaults.toml`); `audio.toml` пишет игра (`/music` сохраняет `enabled`, `volume`, `ambient`)
  и применяет поверх `config.toml` — ручная правка `[audio]` слабее `/music`.
- Заменить трек: положите файл с тем же именем в `src/ai_dm/audio/data/` (OGG; имена — в `index.yaml`). Лицензии — `ATTRIBUTION.md` там же.
- Страшные места (теги «чаща», «тёмный лес», «топь») и природа при тоне ужаса «сильно» играют тему `wilds`; для романтики тона «откровенно» есть тема
  `romance_sensual` (запуск романтики автоматически пока не включён). Всё это — таблица `index.yaml`.
- Тема локации выбирается по тегам локации (таблица `src/ai_dm/audio/data/index.yaml`); смена темы — не чаще раза в 20 с, бой — сразу.

## Как добавить рисунок

Рисунки лежат в `src/ai_dm/art/data/`: один рисунок — один файл `<id>.txt`, ссылки — в `index.yaml`.
1. Нарисовать файл `<id>.txt`: обычный рисунок до 36 колонок × 14 строк (заставка `title` — до 76×16), символы только
   ASCII (0x20–0x7E) и штриховка `░▒▓`, без табов и пробелов в конце строк. `[` и `]` можно: рисунок выводится как текст, не как разметка.
2. Прописать id в `index.yaml`: `locations` (id локации), `location_tags` (тег локации), `monsters` (id монстра),
   `creature_types` (тип существа) или `events` (title, victory, death, level_up). Файл без ссылки не допускается.
3. Рисунки локаций и событий показываются в панели «Рисунок» TUI (при входе в локацию и по событиям), рисунок монстра печатается в ленту
   один раз в начале боя; в простом режиме — только заставка.

## Симулятор боя

```
uv run python -m ai_dm.devtools.sim_combat --seed 3 --scenario goblins3
```

Параметры: `--variant weak` (слабый герой — волшебник), `--intent kill|capture|rob|drive_off|spare` (намерение
группы гоблинов), `--find-outcome <исход>` (перебор сидов до нужного исхода, `--limit` — сколько), `--seed N`.

## Документы

- `docs/TZ.md` — техническое задание.
- `docs/ARCHITECTURE.md` — архитектура; часть C — этап 2.
- `docs/plan-<шаг>.md` — документ каждого шага: план, решения, правки по ревью, итог (`docs/plan-stage2.md` — этап 2 и чек-лист ручной живой сцены).
- `docs/research/` — ресёрчи (локальные модели, музыка, OpenAI, Gemini 503, пресеты 18+).
- `docs/rules-adaptation.md` — где движок отходит от SRD 5.2.
- `docs/glossary.md` — термины и русские названия.
- `docs/ROADMAP.md` — карта очереди, `docs/BACKLOG.md` — отложенное, `docs/done/` — закрытые пункты, `docs/handoff.md` — закладка для новой сессии.
- `AGENTS.md`, `docs/RULES.md` — как работаем и правила docs/.
